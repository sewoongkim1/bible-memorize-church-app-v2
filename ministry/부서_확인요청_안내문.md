# 부서 확인 요청 — 보낼 문안

> 2027 사역신청을 앱으로 받기 위해 **각 부서에 사역팀 이름·시간을 확인받는** 단계다.
> 이 확인이 끝나야 앱의 사역 목록(`ministry_catalog`)이 확정된다.
>
> **보낼 파일**: `ministry/부서확인/2027_사역신청_확인_{부서명}.xlsx` — 부서마다 **자기 것 하나만**
> 보낸다. 통합본(94팀)을 보내면 부서장이 필터부터 걸어야 해서 회신이 늦어진다.
>
> ⚠️ **온라인 구축 결정과 무관하게 지금 시작해도 되는 일이다.** 종이로 계속 받더라도
> 팀 이름·시간은 어차피 확정해야 한다.

## 1. 카톡·문자용 (짧게)

```
○○부장님, 안녕하세요 🙂

내년(2027) 사역신청을 준비하면서 부서별 사역팀 목록을 정리하고 있습니다.
○○부 것만 따로 담은 파일 하나 보내드립니다.

지금 있는 이름이 맞는지만 봐주시고, 사역 시간·하는 일을 한 줄씩만
적어 주시면 됩니다. 성도님들이 신청할 때 "이 사역이 언제 무엇을 하는지"를
몰라 고르기 어려워하셔서 올해 처음 여쭙는 항목입니다.

9월 ○○일까지 회신 주시면 감사하겠습니다.
바쁘시면 이름만 확인해 주셔도 괜찮습니다. 감사합니다!
```

## 2. 메일용 (조금 더 자세히)

```
제목: [2027 사역신청] ○○부 사역팀 확인 요청 (~9월 ○○일)

○○부장님, 안녕하세요.
방송전산부 전산팀입니다.

내년 사역신청을 준비하면서, 부서별 사역팀 목록을 최신으로 맞추고 있습니다.
첨부 파일에 ○○부 사역팀만 담았습니다(다른 부서 것은 없습니다).

■ 확인 부탁드릴 것 — 3가지
  1. 사역팀 이름이 2027년 기준으로 맞는지 (바뀌었으면 K열에 적어 주세요)
  2. 사역 시간·요일 (F열) — 예: "매주 화 오전 10시", "주일 예배 전"
  3. 하는 일 한 줄 (G열) — 예: "주일 예배 전 주차 안내"

  2·3번은 올해 처음 여쭙는 항목입니다. 지금 신청서에는 팀 이름만 있어서,
  성도님들이 "오병이어 1팀과 2팀이 무엇이 다른지" 알 수 없는 채로
  고르셔야 했습니다. 짧게 한 줄이면 충분합니다.

■ 색이 칠해진 줄
  - 분홍색: 신청서와 조직표의 표기가 서로 달라 확인이 필요한 자리입니다
  - 회색: 지명(임명)으로 정해지는 자리입니다. 이름만 봐주시면 됩니다

■ 회신
  9월 ○○일까지 이 메일로 답장 주시면 감사하겠습니다.
  회신이 어려우시면 지금 적힌 이름 그대로 진행하겠습니다.

파일 안 「안내」 시트에도 같은 내용이 적혀 있습니다.
궁금한 점 있으시면 편하게 연락 주세요. 감사합니다.

방송전산부 전산팀 드림
```

## 보내기 전에 정할 것

| 정할 것 | 메모 |
|---|---|
| **회신 기한** | 2주가 무난하다. 위 문안의 `9월 ○○일`을 채운다 |
| **보내는 경로** | 부서장 직접 / 교역자 회의에서 한 번에 / 위원회 서기 경유 |
| **회신 받을 곳** | 메일·카톡 중 하나로 통일해야 취합이 쉽다 |

⚠️ **「회신이 없으면 초안대로 간다」를 문안에 넣어 둔다.** 이게 없으면 답을 안 준
부서 때문에 전체가 멈춘다. 넣어 두면 늦어도 진행은 된다.

## 파일을 보내지 않는 부서

개별 사역팀이 없고 임명직만 있는 곳이라 확인할 것이 없다.

- **M-12부** — 행정운영·리더 전원 임명직
- **재정부** — 회계·계수·재무 전원 임명직
- **감사위원회** — 감사위원 임명직
- **당회 · 제직회** — 담임목사 직속, 사역신청서 대상 아님

## 회신을 받은 뒤 — 손으로 옮기지 않는다

채워져 온 엑셀을 **`ministry/부서확인/회신/` 폴더에 그대로 넣고** 도구를 돌린다.
94행 × 네 칸을 손으로 옮기면 반드시 어딘가 틀리고, **틀려도 티가 안 나는 것이 더
문제**다 — 그대로 성도님 화면에 나간다.

```bash
python tools/ministry-merge-replies.py        # 회신 취합 → 확정본 + 결과 보고
python tools/ministry-apply-form-gen.py       # 종이 신청서(3단 체크리스트)
python tools/ministry-apply-form-table-gen.py # 종이 신청서(표 형식)
python tools/ministry-demo-gen.py             # 데모
```

- 취합 도구가 **`ministry_catalog_2027.json`(확정본)** 과
  **`부서확인/_취합결과.md`(무엇이 바뀌었는지)** 를 만든다.
- 초안(`..._draft.json`)은 덮지 않는다 — 그건 `ROWS`에서 다시 만들어지는 파일이라
  덮어 봐야 다음 실행에 지워진다.
- 아래 세 생성기는 **확정본이 있으면 그것을, 없으면 초안을** 읽는다. 그래서 취합만
  하면 나머지는 다시 돌리기만 하면 된다.

### 2026-09-08 예행 연습에서 확인한 것

회신이 온 상황을 만들어 끝까지 돌려 봤다(모의 자료는 저장소에 남기지 않았다).

- 이름 변경·폐지·신설·미회신 네 경우가 모두 의도대로 처리됐다
  (13/15 부서 회신 가정 → 미회신 2곳은 초안 그대로 두고 보고서에 이름을 적어 준다).
- **시간 칸이 빈 채로 온 팀을 따로 뽑아 준다** — 회신은 왔는데 시간이 비면
  성도님 화면에 시간이 안 보이므로, 그 목록만 다시 물으면 된다.
- ⚠️ **표 형식 신청서는 실제 시간이 채워지면 2장 → 3장이 된다.** 팀마다 시간이
  달라져 체크박스 옆 시간 표기가 늘기 때문이다. 형식을 표 쪽으로 정하면 그때
  `.screens-stage` 배율처럼 **배율을 다시 재서 잡아야 한다**(3단 체크리스트
  신청서는 2장 그대로였다).
