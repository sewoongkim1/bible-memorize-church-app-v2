# 가정 축복 기도문 — 카톡·문자로 보내기 (설계 · 2026-11-04)

> 친구 요청(2026-11-04): 「이름을 수정해서 카톡, sms 공유할 수 있게 · 디자인도 선택을 해서 배경을 넣으면」.
> 정한 것: **그림 한 장**을 보낸다 · 배경 **네 가지 모두**(액자 · 잎 한 가지 · 남색 밤하늘 · 풍경 사진) · 풍경 사진은 **AI 그림** ·
> 그림 맨 아래는 **교회 마크만**(글씨 없음) · 보내는 길은 **폰 공유 창**(1번 안).
> 손대기 전에 읽을 것: `docs/notes/prayer-book.md`(조사 ㄹ 받침 · 액자 잎가지 · 어두운 모드) · `docs/notes/lazy-load.md`.

## 1. 무엇을 만드나

기도문 화면(`js/prayer.js` `drawPrayer`)의 맨 아래에 **「📤 카톡·문자로 보내기」** 단추 하나를 더한다. 누르면 아래에서 판이 올라온다.

1. **누구를 위한 기도인가요?** — 이름 칸. 처음 값은 지금 화면의 이름(`prayName` · 👤 단추와 같은 값). 12자까지(`askPrayName` 과 같다).
2. **배경 고르기** — 작은 그림 줄(가로로 밀기): 액자 · 잎 · 밤하늘 · 풍경 사진 여러 장.
3. **미리보기** — 지금 고른 이름·배경으로 만든 그림 그대로(캔버스 결과를 `<img>` 로).
4. **「보내기 (카톡 · 문자)」** — 폰의 공유 창을 띄운다. 성도님이 거기서 카카오톡 · 메시지(문자) · 밴드 중에 고른다.
   아래 한 줄: 「폰의 공유 창에서 카카오톡이나 메시지를 골라 주세요」.

판의 ✕ · 바깥 어둠막 · 안드로이드 뒤로 가기로 닫힌다. 이름을 판에서 바꿔도 **그림에만** 쓴다 — 기도문 화면의 이름(`prayName`)은 그대로다.

### 하지 않는 것
- 카카오 SDK(카카오톡 공유 API) — 개발자 등록 · 그림을 서버에 올려야 함(새로 모으는 것 → 방침 고침) · 문자는 따로. 버렸다.
- 글(텍스트)로 보내기 · 그림과 글 함께 — 친구가 「그림 한 장」을 골랐다.
- 서버 저장 · 기록(`feature_log`) — 이번에는 없다(값을 늘리려면 SQL 허용 목록까지 세 곳 — 쓰임을 재고 싶어지면 그때). (2026-11-06 바뀜 — 보내기 기록을 남긴다 · `2026-11-06-share-board-usage-log-design.md`)
- 「크게 보기」 덮개 안의 보내기 단추 — 기도문 화면 단추 하나로 충분하다.

## 2. 그림

- 크기 **1080 × 1350**(세로 4:5 — 카톡 말풍선 · 문자에서 잘리지 않는 꼴). **JPEG**(품질 0.9 — 사진 배경을 PNG 로 두면 2MB 를 넘는다).
- 안에 든 것(위에서 아래로): **제목** · **말씀 자리**(`b.ref` 그대로 — 「열왕기상 4:29-30」) · (배경에 따라 ❖ 장식) · **기도문**(이름 · 조사 채움) ·
  **맺음말** 「예수님의 이름으로 축복하며 기도합니다. 아멘!」(`PRAY_AMEN`) · 맨 아래 가운데 **교회 마크**(`img/logo-mark.png` 108×132 · 글씨 없음).
- 이름은 굵게 + 배경마다 정한 강조색(액자 금색 등). 맺음말도 강조색.
- 이름 채우기는 **`prayFill`(app.js)** 을 그대로 쓴다 — 받침 · ㄹ 받침 규칙이 거기 있다. ⚠️ 문자열 치환으로 따로 채우지 말 것(prayer-book.md).
- **글씨 크기는 저절로 맞춘다** — 가장 긴 편(40번 · 247자 · 이름이 열두 자여도)이 글 상자 안에 들어갈 때까지 큰 크기에서 줄여 내려간다.
  줄은 **낱말(띄어쓰기) 단위로** 접는다(화면의 `word-break: keep-all` 과 같다 — 낱말 하나가 한 줄보다 길 때만 글자로 끊는다).
  문장 사이(`prayChunks` 의 나눔)는 반 줄 띄운다. 기도문 글씨는 **46px 에서 2px 씩 줄여 28px 까지**(1080 폭 기준 · 줄 간격 1.7) —
  28px 로도 넘치면 28px 로 두고 글 상자를 아래로 늘린다(마크 위까지). 제목은 기도문의 1.45배 · 말씀 자리는 0.8배.

### 배경 네 가지
| 이름 | 바탕 | 글꼴 · 맞춤 | 글자색 / 강조색 |
|---|---|---|---|
| **액자** | 크림 바탕 + 금색 겹테두리 + 아래 두 귀퉁이 수채화 잎가지(`img/frame/leaf1~12.webp` 중 하나 — 판을 열 때 하나 뽑고, 같은 칸을 다시 누르면 다른 잎) | 나눔명조 · 가운데 | 남색 `#1e3264` / 금색 |
| **잎 한 가지** | 옅은 연둣빛 그러데이션 + 오른쪽 위 큰 잎가지 하나(같은 잎 소재) | Noto Sans KR · 왼쪽 | 짙은 초록 / 금갈색 |
| **남색 밤하늘** | 남색 방사 그러데이션 + 작은 별(캔버스로 찍는다 · 그림 파일 없음) | 나눔명조 · 가운데 | 크림 / 금색 |
| **풍경 사진** | AI 그림 한 장(새벽 햇살 · 들판 · 바다 · 꽃길 …) + 글 아래쪽을 어둡게 덮는 막 | Noto Sans KR · 왼쪽 · 아래쪽 | 흰색(그림자) / 노란 금색 |

- 풍경 사진은 **친구가 고른 4~6장**. 그림 줄에 사진마다 한 칸씩(액자 · 잎 · 밤하늘 다음).
- 시안: `brainstorm` 시안 창(2026-11-04) — 액자 · 잎 · 밤하늘 · 사진 네 칸과 보내기 판 그림.

### 풍경 사진 만들기(한 번)
- Gemini(`gemini-3-pro-image`)로 세로 4:5 풍경을 넉넉히(10~12장) 그린다. 사람 · 글자 · 십자가 등 상징물 없이, 아래 40% 는 글이 올라가도 읽히게 단순하게.
- 🔑 **키가 필요하다** — 연상 그림의 `GEMINI_API_KEY` 는 Supabase 비밀값이라 이 PC 에서 꺼내 쓸 수 없다. 친구가 이 PC `.env` 에
  `GEMINI_API_KEY` 를 넣어 주면 스크래치 스크립트로 부른다(값은 찍지 않는다). 안 되면 친구가 Gemini 앱에서 그려 폴더에 넣어 준다.
- 친구가 고른 것만 **`img/share/bg-*.webp`**(1080×1350 · WebP q≈78 · 한 장 150KB 이하)로 줄여 저장소에 넣는다. 원본 · 버린 것은 저장소 밖.
- `img/` 는 이미 사이트로 나가는 폴더다(`tools/site.py` SITE_DIRS) — 새 폴더를 따로 더하지 않아도 된다(확인만).

## 3. 코드 짜임

- **새 파일 `js/pray-share.js`(지연)** — `LAZY_JS` 에 `prayShare: { src: "js/pray-share.js", fn: "openPrayShare" }`. 단추를 누를 때 받는다
  (기도문 화면이 무거워지지 않게 · `docs/notes/lazy-load.md` 규칙 · 첫 화면이 동기로 부르는 것은 이 파일에 두지 않는다).
  - **순수 구간**(`// ── 기도문 그림 — 순수 (여기부터/여기까지) ──`): `prayShareStyles`(배경 네 가지 값표) ·
    `prayShareRuns(prayer, name)`(문장 → 「보통 / 강조(이름)」 토막 — `prayFill` 을 이름 자리에 표식을 넣어 부른 뒤 가른다) ·
    `prayShareWrap(runs, maxW, measure)`(낱말 단위 줄 접기) · `praySharePlan(b, name, style, measure)`(→ 그릴 것 목록 `ops` · 글씨 크기 셈).
    `measure` 를 밖에서 받는다(교육 수료증 `eduCertPlan` 과 같은 꼴) — 시험이 캔버스 없이 돈다.
  - **그리기** `prayShareDraw(b, name, styleKey)` → `Promise<Blob>`: 글꼴을 먼저 받고(`document.fonts.load` — 쓰는 글자만 · 5초 안 오면 기기 글꼴로 ·
    수료증과 같은 꼴) · 배경 그림(잎 · 사진 · 마크)을 받은 뒤 `ops` 대로 그린다. 그림을 못 받으면 그 그림만 빼고 그린다(잎이 없는 액자 · 사진 대신 남색).
  - **판** `openPrayShare(b, name)` — 판 그리기 · 이름 칸(입력이 멎은 뒤 0.3초에 다시 그림) · 배경 칸 누르면 다시 그림 · 보내기.
- **`js/prayer.js`** — `drawPrayer` 에 단추 한 줄(문 안에서만) + 누르면 `loadLazyJs("prayShare")`(app.js) 뒤 `openPrayShare(list[i], prayName)` · 못 받으면 「잠시 뒤 다시 눌러 주세요」.
- **`style.css`** — 판 · 그림 줄 · 미리보기 · 단추(묵상 A 판과 같은 옷 · 어두운 모드 짝 — CLAUDE.md 「새 글자색을 `--navy`… 로 쓰면 `.dark` 짝」).

### 보내기
```
file = new File([blob], "축복기도문.jpg", { type: "image/jpeg" })
navigator.canShare({ files: [file] }) 이면 → navigator.share({ files: [file] })   // 폰 공유 창
  · AbortError(성도님이 닫음) → 아무 말 없음
  · 그 밖의 실패 → 내려받기로
아니면 → <a download> 로 내려받기 + 「그림 파일 내려받기를 시작했어요」
늘 미리보기 아래에 「안 되면 그림을 길게 눌러 저장해 주세요」
```
- ⚠️ `share` 는 **누른 그 탭 안에서** 불러야 한다(사용자 동작이 식으면 막힌다) — 그래서 그림은 「보내기」를 누를 때 만들지 않고,
  **미리보기를 그릴 때 이미 만든 Blob** 을 쓴다. 이름 · 배경이 바뀌는 중(다시 그리는 중)이면 단추를 잠깐 「그리는 중…」으로 막는다.
- `title`·`text` 는 넣지 않는다 — 카톡이 그림과 글을 함께 받으면 글을 따로 보내거나 빼는 판이 있다(「그림 한 장」).

## 4. 문(게이트)과 여는 차례

- `PRAY_SHARE_PUBLIC = false`(js/prayer.js 머리 상수) · 보이는 조건 `PRAY_SHARE_PUBLIC || ministryTesterCached()` — 🧪 시험 참여자에게만.
  문이 닫혀 있으면 단추를 그리지 않는다(눌러도 막는 꼴이 아니라 **없다**).
- 여는 차례: ① 시험 참여자로 운영 배포 → ② 친구 폰에서 확인(아래 6) → ③ `PRAY_SHARE_PUBLIC = true` 한 줄 + bump → 모든 성도님.
- 서버 · SQL · 개인정보 방침은 바뀌지 않는다 — 그림은 폰 안에서만 만들어지고, 보내는 것은 성도님이 고른 앱이 한다. (2026-11-06 바뀜 — 보내기 기록을 남긴다 · `2026-11-06-share-board-usage-log-design.md`)
  (플레이 심사 중 방침 금지 규칙에 걸리지 않는다.) 도움말 · 설명서에 한 줄 더하는 것은 문을 연 뒤.
