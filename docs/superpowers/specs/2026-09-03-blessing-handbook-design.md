# 가정 축복 기도문 핸드북 (A5) — 기획서

2026-09-03 · 초안. **결정이 필요한 곳은 「■ 정해 주실 것」에 모았다.**

---

## 1. 왜 만드나

앱의 「가정 축복 기도문」 104편을 **손에 드는 책**으로 옮긴다.

앱과 종이는 하는 일이 다르다.

| | 앱 | 핸드북 |
|---|---|---|
| 언제 | 혼자, 틈날 때 | **가정 예배 · 식탁 · 잠자리** |
| 누가 | 본인 | **온 식구가 함께** |
| 쓰기 | 없음(읽기만) | **날짜·묵상을 적는다** |
| 이름 | 로그인 이름이 자동 | **인쇄된 그 사람 이름** |

핸드북에서만 되는 것이 **묵상노트**와 **날짜 기록**이다. 한 편을 읽고 그날 무엇을
받았는지 적어 두면, 한 해가 지나 다시 펼쳤을 때 그게 기도의 응답 기록이 된다.

## 2. 한 쪽의 구성 — 샘플 그대로

샘플(창조의 축복)을 A5로 옮긴다. 위에서 아래로:

```
┌──────────────────────────────────┐
│           창조의 축복              │  ① 제목 — 가운데·굵게
│  창세기 1:28-29      2026 년 월 일 │  ② 요절(왼) · 날짜 기입란(오른)
│ ──────────────────────────────── │
│  하나님이 그들에게 복을 주시며…      │  ③ 말씀 — 개역개정 원문, 밑줄 위에
│ ──────────────────────────────── │     (읽으며 밑줄을 긋거나 표시하는 자리)
│  ※ 축복 기도문에 자신의 삶과 가족,   │  ④ 안내 한 줄
│     친구들을 위해 이름을 넣어 기도합니다│
│ ┌──────────────────────────────┐ │
│ │  하나님, 김세웅에게 복을 주시며   │ │  ⑤ 기도문 상자 — 이름이 **인쇄**되어 있다
│ │  …                            │ │     맺음말까지 포함
│ │  예수님의 이름으로 축복하며       │ │
│ │  기도합니다. 아멘!              │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────── ┐  │
│ │                     묵상노트  │  │  ⑥ 묵상노트 — 빈 상자
│ └──────────────────────────── ┘  │
│ God is love.  2026년 비전 …    12 │  ⑦ 꼬리말 · 쪽번호
└──────────────────────────────────┘
```

⚠️ **③ 말씀은 필사가 아니라 읽는 자리다.** 줄은 밑줄을 긋거나 표시하기 위한 것이고,
개역개정 원문을 그대로 인쇄한다(마침표 없음 — 앱과 같은 자료).

⚠️ **⑤ 기도문에는 맺음말이 들어간다** — 「예수님의 이름으로 축복하며 기도합니다. 아멘!」
앱에서는 코드가 붙이지만 책에서는 인쇄물의 일부다.

## 2-1. 2026-09-03 확정 — 축복 기도문만, 한 편 한 쪽

**성경 본문은 이 책에 넣지 않는다.** 한 쪽에 축복 기도문 하나뿐이다.

```
        창조의 축복            ← 19pt
창세기 1:28-29    2026 년 월 일  ← 11pt
────────────────────────────
   하나님, 김세웅에게 복을 주시며   ← 14pt · 마디로 줄바꿈
   김세웅에게 말씀하여 주옵소서.      이름은 1.12배·굵게·금갈색
   …
   예수님의 이름으로 축복하며 기도합니다. 아멘!
┌──────────────── 묵상노트 ┐  ← 남는 자리를 그대로 차지
└──────────────────────┘
God is love. 오직 말씀, 성경이 답이다!  6
```

**권당 58쪽 · 두 권**(52편씩).

### 글씨 크기는 14pt — 손계산이 아니라 실측으로 정했다

⚠️ 손으로 계산하니 16pt 가 나왔는데 **브라우저로 재 보니 7쪽이 넘쳤다.**
한 마디가 목표 글자 수를 넘으면 브라우저가 **한 번 더 접는데** 그것을 안 셌기 때문이다.

| | 넘친 쪽 |
|---|---|
| 16pt | 7쪽 |
| 15pt | 3쪽 |
| **14pt** | **0** |

**크기를 바꾸려면 반드시 브라우저로 다시 잴 것.**

아래 박스는 편마다 다르다 — 가장 좁은 편 6mm(20번 평화의 축복), 가장 넓은 편 101mm.
기도문이 길수록 좁아지는 것이 자연스럽다.

### 시도했다가 되돌린 것 — 말씀 따라 쓰기

샘플처럼 「한 줄 인쇄 + 그 아래 쓰는 줄」을 넣어 봤다. 기도문 12pt 에 그것까지 얹으니
A5 한 쪽에 **104편 중 36편**만 들어가(말씀 10pt·묵상노트 빼도 83편) 한 편을 펼침
두 쪽으로 벌렸다가, **성경을 빼기로 하면서 되돌렸다.**
⚠️ 샘플이 한 쪽에 다 담긴 것은 그 샘플이 **A4** 이기 때문이다(면적이 두 배).

## 3. 판형과 분량

| | |
|---|---|
| 판형 | **A5 (148 × 210mm)** |
| 여백 | 13mm(위·좌·우) · 17mm(아래, 꼬리말 자리) |
| 본문 한 편 | **한 쪽** |
| 본문 쪽수 | 104쪽 |
| 부속 | 표지·속표지·사용법·차례(2)·맺음말 — 약 8쪽 |
| **합계** | **약 112쪽** (제본상 4의 배수로 맞춘다) |

### 실측 — 한 쪽에 들어가나

104편의 말씀·기도문 길이를 재어 A5 한 쪽(본문 높이 168mm)에 넣어 봤다.

| | 편수 |
|---|---|
| 여유 있음 (묵상노트 25mm 이상) | **96편** |
| 빠듯함 (묵상노트 25mm 미만) | 7편 |
| **한 쪽에 못 들어감** | **1편** — 36번 십일조의 축복(신 26:12-15), 19mm 넘침 |

말씀 길이 중앙값 133자·최장 410자, 기도문 중앙값 154자·최장 259자.

**→ 「한 편 = 한 쪽」으로 간다.** 넘치는 한 편은 그 쪽만 글씨를 한 단계 줄인다
(기존 필사노트에 이미 `.sermon.big` 같은 쪽별 조절이 있다).

⚠️ **모든 쪽을 같은 글씨 크기로 맞추려고 하면 안 된다** — 가장 긴 편에 맞추면
나머지 103쪽이 다 작아진다. 넘치는 쪽만 줄이는 것이 싸다.

## 4. 이름을 어떻게 넣나

「이름은 이미 알고 있다」는 전제이므로 **빈칸이 아니라 인쇄된 이름**으로 간다.

```
샘플(빈칸)   __ __ __(이)에게 복을 주시며
핸드북       김세웅에게 복을 주시며
```

토큰은 앱과 같은 것을 쓴다: `{이름}` `{이}` `{을}` `{은}` `{과}` `{으로}`

⚠️ **조사는 ㄹ 받침이 함정이다.** 받침이 없거나 **ㄹ 받침**이면 「로」다.

```
오연화로 (받침 없음)   김윤월로 (ㄹ)   김세웅으로 (ㅇ)
```

말씀 카드(`말씀카드_접이만들기.py`)에 이미 있는 규칙을 그대로 옮긴다.
128명 명단에서 **일곱 분이 ㄹ 받침**이라 실제로 걸리는 문제다.

## 5. 만드는 법 — 있는 것을 쓴다

`booklet/`에 **A5 필사노트 파이프라인이 이미 있다.** 새로 만들지 않는다.

```
blessings.json  →  booklet/generate_blessing.py  →  blessing.html  →  브라우저 인쇄 → PDF
                          (기존 generate.py 를 본뜬다)
```

가져다 쓸 것:
- `.page { width:148mm; height:210mm; padding:13mm 13mm 17mm }` — A5 한 쪽
- `.wline { height:8mm; border-bottom:.6px solid }` — 말씀 밑줄
- 글꼴: 본문 `Noto Sans KR`, 제목·말씀 `Nanum Myeongjo`
- 표지·차례·맺음말 만드는 함수들의 얼개

⚠️ **`1mm = 96/25.4 = 3.7795px` 고정이다** — 창 너비에 따라 늘어나지 않는다.
넘치는지는 반드시 **측정으로** 확인한다(사용설명서에서 이걸 헷갈려 멀쩡한 판을
넘쳤다고 오인한 적이 있다).

## 7. 차례를 어떻게 짜나 — **본문은 성경 순**

**본문 배열은 성경 순 그대로 간다**(창세기 1편 → 시편 104편). 자료가 이미 그 순서이고
어긋난 자리가 없는 것을 확인했다.

성경 순으로 가는 이유:
- **찾기가 한 가지 규칙으로 끝난다.** 「신명기 어디쯤」이면 성경을 떠올리는 그대로 넘기면 된다
- 주제 순으로 놓으면 **같은 책이 흩어진다** — 시편 31편이 아홉 주제에 나뉘어 흩어진다
- 주제 분류는 사람이 정한 것이라 바뀔 수 있지만 **성경 순서는 안 바뀐다**.
  나중에 주제를 손봐도 책을 다시 짜지 않아도 된다

```
창세기  5편   출애굽기 10   레위기 5   민수기 1   신명기 28
여호수아 5    사사기 1     사무엘상 2  사무엘하 5  열왕기상 5
역대상 2     역대하 1     욥기 3     시편 31
```

⚠️ **신명기 28편·시편 31편이 절반을 넘는다.** 성경 순으로 죽 늘어놓으면 그 구간이
길게 이어지므로, **책 이름이 바뀌는 자리에 표시**를 두어 어디쯤인지 알게 한다
(쪽 가장자리 색인 또는 간지).

## 7-1. 주제는 **뒤쪽 색인**으로

주제 그룹은 차례를 대신하지 않고 **책 뒤에 「주제로 찾기」 색인**으로 넣는다.
「오늘은 아픈 식구를 위해」 하고 찾을 때 쓰는 길이다.

```
하나님이 지키심 ····· 9, 10, 12, 18, 19, 25, 37 …
```

### 주제별 편수

| 주제 | 편수 | | 주제 | 편수 |
|---|---|---|---|---|
| 하나님이 지키심 | 22 | | 함께 하심 | 9 |
| 말씀에 순종 | 19 | | 싸움에 이김 | 8 |
| 기도와 응답 | 12 | | 이웃을 섬김 | 6 |
| 믿음의 사람들 | 12 | | 지혜와 형통 | 5 |
| 가정과 자손 | 11 | | | |

⚠️ **아직 담당자 검토 전이다.** 제목의 낱말로 짐작한 것이고, 다섯 편(22·41·56·74·75)은
본문을 보고 손으로 넣었다. 차례를 주제로 짤 거라면 **인쇄 전에 확정**해야 한다.

## ■ 정해 주실 것

### ① 몇 사람 몫인가 — 이게 제작 방식을 가른다

| | 어떻게 | 비용·수고 |
|---|---|---|
| **가) 한 사람용** | 이름 하나로 한 권 | 가장 쉽다. 시험 삼아 한 권 뽑아 보기에 좋다 |
| **나) 명단 전체** | 128명 각자 다른 책 | ⚠️ **128 × 112쪽 = 14,336쪽.** 인쇄소에서 한 권씩 다르게 찍어야 해 값이 크게 뛴다 |
| **다) 이름 없이 공용** | 샘플처럼 `__ __ __(이)` 빈칸 | 한 판으로 여러 권. 대신 쓸 때마다 이름을 떠올려야 한다 |
| **라) 섞기** (권함) | 본문은 공용(빈칸), **표지에만 이름** | 인쇄는 한 판, 받는 분은 자기 책. 값과 정성을 함께 얻는다 |

### ② 분량 — 104편 전부인가

104편이면 112쪽이라 제법 두껍다. 주제별로 추려 **한 주제씩 얇은 책 아홉 권**으로
내는 길도 있다(「하나님이 지키심 22편」처럼). 가정 예배에서 한 주제를 한 달씩 쓰기 좋다.

### ③ 묵상노트 크기

지금 계산으로는 편마다 남는 자리가 다르다(96편은 25mm 이상, 7편은 그 미만).
**모든 쪽을 같은 크기로 맞출지**, **남는 만큼 주는지** 정해야 한다.
→ 같게 맞추면 단정하지만 긴 편은 글씨를 줄여야 한다.
