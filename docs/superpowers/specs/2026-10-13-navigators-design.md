## 2. 화면(성도님이 보시는 것)

1. **첫 화면** — 「말씀 묵상」 아래 새 묶음 「암송 과정」에 줄 하나 「📚 네비게이토 성경암송」. 지금 첫 화면(A안 · `applyHomeA` 옮겨 담기)과 옛 첫 화면(롤백용 템플릿) 둘 다에 자리를 둔다 — 템플릿에 묶음 제목 + 단추, A안 `HA_GROUPS`·`HA_ROW_ICON` 에 한 자리.
   문이 닫힌 동안은 🧪 시험 참여자와 미리보기 주소(`?navi=1`)에만 보인다.
2. **묶음 목록** — 일곱 줄(그리스도인의 확신 5 · 생활 지침 8 · A 새로운 삶 · B 그리스도를 전파함 · C 하나님을 의뢰함 · D 그리스도 제자의 자격 · E 그리스도를 닮아 감). 줄마다 **마친 수만**(「3구절 마침」 · 다 마치면 🎉) — 첫 화면에서 전체 수를 뺀 것과 같은 까닭(새로 오신 분 부담).
3. **구절 목록(묶음 안)** — 말씀 목록 시안 B 와 같은 카드(장절 · 본문 두 줄 · 상태 칩 · 🔊). **주제 이름** 아래 두 구절씩 묶는다. 위에 「▶️ 이 묶음 듣기」.
4. **암송** — 지금과 같은 3단계(0단계 보기·듣기 → 1·2·3단계 빈칸 · 👆 카드 입력 · 반복해서 쓰기 · 「이 말씀을 내 마음에 두었나이다」). 완료 창 「다음」은 **그 묶음 안 다음 구절**, 「← 목록」은 그 묶음 목록.
5. **기록** — 3단계 저장이 주간과 같은 `saveProgress` 를 타서 `progress`·`challenge_log`(learn-*)에 남는다 → 오늘 N회 · 순위 · 도장이 저절로 따른다. 마음에 둠도 같은 `progress.hearted`.

**1단계에서 뺀 것(나중에):** 나의 말씀 앨범 칸 · 묶음별 말씀 도전 · 영어(NIV) · 복습 · 교회 어드민 편집 화면.

## 3. 표 · 서버

- **`verses` 칸 둘 더하기** — `chapter text`(묶음 코드: `assurance` · `guide` · `A`~`E`) · `topic text`(주제 이름). 둘 다 null 허용(주간·시편은 비움). `track` 에는 CHECK 가 없다.
- **번호대** — 묶음마다 띄운다: 5확신 2001~ · 생활 지침 2011~ · A 2021~ · B 2041~ · C 2061~ · D 2081~ · E 2101~(지금 2001~2112). 1~999 는 주간, 1001~1999 는 쉴만한 물가. ⚠️ 한 번 넣은 번호는 바꾸지도 지우지도 않는다(cascade 로 성도님 기록이 지워진다) — 내릴 때는 `is_active=false`.
- **`getVerses` 에 `navi` 갈래** — `track:"navi"` 면 `is_active=true AND track='navi'` 를 번호순으로(chapter · topic 함께). 지금은 psalm 이 아닌 값이 weekly 로 떨어진다(index.ts:1702) — 갈래를 하나 더 둔다. 날짜 잠금 없음.
  주간을 읽는 곳(이번 주 말씀 `latestVerse`·`weeklyVerseKst` · 알림 · 위젯 · monitor · `verseNextNo`)은 모두 `track='weekly'` 로 걸러 섞이지 않는다.
- **「1000 넘으면 물가」 판정 고치기** — `isPsalmNo` 를 **1001~1999** 로: 서버 `index.ts:139-147` · 앱 `js/psalm.js:27`(`PSALM_NO_BASE`) · 지표 `supabase/psalm_metrics.sql:43`. **같은 판에서 셋 다.**
- **복습은 넣지 않는다** — 「1000 넘으면 복습 안 함」은 그대로 둔다(서버 `index.ts:2704`·`2815` · 앱 `app.js:2083`·`2099`). 판정 이름을 「물가」와 「주간이 아님」으로 갈라 쓴다(물가 화면으로 보내는 판정과 복습을 빼는 판정이 다른 뜻이 된다). ⚠️ 한쪽만 막으면 `reviews` 만 조용히 쌓인다(물가 41행 사고).
- **문** — `app_config` `naviPublic`(`PUBLIC_CONFIG_KEYS` 에 키) + 앱 캐시(`naviOpenCached` · 값은 `=== true`) + 미리보기 `?navi=1` + 🧪 시험 참여자(`ministryTesterCached`). 본문 줄은 `is_active=false` 로 심고 여는 날 켠다(데이터 문).
- **열람 기록** — `feature_log` 에 `navi` 를 더할지(FEATURES 허용 목록 · SQL 머리 표)는 여는 날 함께.
- 새 `challenge_log.mode` 값은 **만들지 않는다**(CHECK 제약 · 집계가 learn- 앞머리로 가른다).

## 4. 앱

- **`js/navi.js`**(필요할 때 받기 — `docs/notes/lazy-load.md` 의 등록표) — 묶음 목록 · 구절 목록 · 3단계 · 완료 창 · 완료 화면.
- 3단계는 **쉴만한 물가가 쓴 공용 부품을 그대로** — `pickBlankIndices` · `setupAutoCheck` 의 `onDone` 갈래 · 카드 쟁반(`setCardMode`·`isCardStart`) · `isRepeatPractice` · `heartCheckHtml`/`setupHeartCheck` · `STEP_CHEER` · `speakText`.
  **주간 암송 화면(`startTest`·`renderTestScreen`)은 쓰지 않는다** — 「← 목록」·「다음 말씀」·완료 이전/다음이 전역 `verses`(주간)에 묶여 있다(app.js 6078-6108 · 6973 · 7678-7696).
- 전역 `verses` 에 넣지 않는다 — 별도 배열(`naviVerses`)에 둔다(물가와 같은 까닭 — 첫 화면 수 · 다음 말씀 · 도전 풀 · 복습 대기열이 바뀐다).
- 영어 모드 · 딥링크 `?v=` · 앨범은 1단계에서 네비게이토를 모른다(빠진 것으로 둔다 — 「없는 것」이지 「틀린 것」이 아니게).

## 5. 본문 넣는 차례

1. `python tools/navi-form-gen.py` → `자료/navi/네비게이토_구절입력_73.xlsx`(묶음 · 주제 · 카드 번호 · 장절을 미리 채움 · 본문 칸만 비움).
2. 친구(또는 담당자)가 대한성서공회 성경 읽기에서 **개역개정**을 복사해 본문 칸(I열)에 붙여 넣는다. 생활 지침 8구절의 주제 이름 · 카드 번호 · 장절은 카드 실물로 확인.
3. 검사 도구 `tools/navi-fit.py`(새로 · `psalm-fit.py` 꼴) — 빈칸 · 장절 꼴 · 번호 겹침 · 번호 재배정(이미 들어간 번호의 장절이 바뀌었나) · 글자 수 → `supabase/navi_verses.sql`(칸 추가 + 73줄 `is_active=false` · 여러 번 돌려도 안전 · 켜는 줄은 주석으로 따로).
4. 개발 DB → 화면 확인 → 운영(`sql-applied.py record`).

## 6. 배포 차례(기존 표에 줄을 더하므로 **코드 먼저**)

1. `api` — `navi` 갈래 · `isPsalmNo` 범위 · 복습 판정 이름 · `naviPublic` 허용 키 → 개발 → 운영(`deploy-fn.py`)
2. 앱 — `js/navi.js` · 첫 화면 자리 · `PSALM_NO_BASE` 판정 · 문(닫힌 채) → bump → 푸시
3. SQL — 칸 둘 + 73줄(꺼진 채) · `psalm_metrics.sql` 범위 → 개발 → 운영
4. 🧪 시험 참여자 실기기 확인(안드로이드 앱 · 아이폰 · 큰 글씨 · 어두운 모드)
5. 친구가 정한 날 — 줄 켜기 + `naviPublic=true` + `FEAT_SINCE.navi` + 설명서 한 장(`when: naviVisible`)

- **네비게이토 이름 · 주제 이름 · 번호 체계를 화면에 써도 되는지** — 공개된 허락 정책이 없다. 한국네비게이토선교회 02-336-3387 · 네비게이토 출판사 02-334-3305. 허락 전이면 메뉴 이름을 「주제별 성경암송」으로 바꿔 둘 수 있다(안쪽 묶음 이름은 성경 주제라 그대로).
