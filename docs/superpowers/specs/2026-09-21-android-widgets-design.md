# 안드로이드 위젯 — 이번주 말씀 · 오늘의 묵상 · 오늘의 축복 기도문 (설계)

**날짜**: 2026-09-21
**배경**: 아이폰 1.1.0(위젯 셋)이 2026-09-21 심사에 올라갔다. 안드로이드 앱은 PWABuilder 로 만든
TWA(Trusted Web Activity) 껍데기라 **저장소에 소스가 없고**, 위젯은 네이티브 코드가 있어야 한다
(안드로이드 크롬은 PWA 위젯을 지원하지 않는다). 친구와 정한 것(2026-09-21 대화):
- **로컬에서 만들어 친구 폰(USB 연결 가능)으로 시험하고, 플레이스토어에는 9/27 프로덕션 승인 뒤에 올린다.**
  9/13 반려 뒤 「테스터 12명 · 14일」을 다시 채우는 중이라 그 사이에는 Play Console 에 아무것도 올리지 않는다.
- 방법은 **A — Bubblewrap 으로 지금 앱과 같은 TWA 프로젝트를 소스째 만들고, 거기에 위젯을 더한다.**
- 위젯 셋의 내용·규칙은 **아이폰과 같다**(`2026-09-20-ios-widgets-design.md` — 9/21 실기기 뒤 바꾼 것까지).

### 왜 A 인가 (버린 길)
- **B — TWA 를 손으로 처음부터**: 결과가 A 와 같고 일만 많다.
- **C — 아이폰처럼 Capacitor 로 바꾸기**: ⚠️ **업데이트하는 순간 성도님 로그인이 풀린다** — TWA 는 기록을 크롬에
  두고 Capacitor 는 앱 자체 웹뷰에 두므로 localStorage 가 이어지지 않는다. 그리고 **안드로이드 웹뷰는 웹 푸시를 못 해서
  아침 알림이 멈춘다**(FCM 으로 새로 짜야 한다). 위젯 하나에 치를 값이 아니다.
- A 의 대가: 위젯을 넣은 뒤에는 `bubblewrap update`(프로젝트 다시 만들기)를 쓰지 않는다 — 우리가 고친 파일을 덮어쓴다.
  그 뒤로는 Gradle 프로젝트를 직접 관리한다.

## ① 위젯 셋과 모양

| 위젯 | 크기(칸) | 보여 주는 것 | 누르면 |
|---|---|---|---|
| **이번주 말씀** | 4×2 로 놓이고, 세로로 4×4 까지 늘릴 수 있다 | 마크 + 「이번주 말씀」 / 본문 / 구절 이름. 4×4 로 늘리면 **같은 말씀을 글씨만 크게** | `/?v=번호` — 그 구절 암송 화면 |
| **오늘의 묵상** | 4×2 → 4×4 | 마크 + 「오늘의 묵상 · 월요일」 / 제목 / 본문 — **적용 질문 없음** | `/?w=meditation` — 매일 묵상 창 |
| **오늘의 축복 기도문** | 4×2 → 4×4 | 마크 + 제목 · 출처 / 기도문(「우리 가족」으로 채움) | `/?w=prayer` — 기도문 화면 |

- **아이폰에서 9/21에 정한 것을 그대로 옮긴다**: 작은 정사각형 없음(4×2 보다 작게 못 줄인다 — 69자 구절이 잘린다) ·
  교회 마크는 **이름 옆에만**(글 뒤 워터마크 금지 — 기도문 액자에서 대비가 1.86:1 까지 떨어졌다) ·
  묵상은 본문만(본문이 비고 질문만 오는 날에만 질문을 본문 자리에).
- 안드로이드는 크기를 셋 중에 **고르지 않고 놓은 뒤 모서리를 끌어 늘린다.** 그래서 위젯이 받은 높이를 보고
  모양을 고른다 — 낮으면 가로로 긴 모양, 충분히 높으면 큰 글씨 모양. 긴 글은 글씨가 줄어 끝까지 들어가게 한다.
- 교회 마크: 아이폰과 같은 그림(루트 `icon-512.png` 에서 여백을 잘라 낸 것)을 앱 리소스로 넣는다.
- 글꼴은 명조(serif) 계열, 어두운 모드는 폰 설정을 따른다.
- **잠금 화면 위젯은 없다** — 안드로이드 폰에는 그 자리가 없다(일부 태블릿뿐).
- 겹쳐 두고 넘기기: 삼성 폰은 위젯 스택이 있다. 다른 폰은 런처마다 다르다 — 우리가 따로 만들 것은 없다.

## ② 누르면 · 새로 고침 · 실패 대비

**누르면**
- 위젯이 `https://gocheok.onlybible.kr/?v=38` · `/?w=meditation` · `/?w=prayer` 로 **자기 앱**(패키지를 지정한
  VIEW 인텐트)을 연다. 아이폰은 앱 전용 스킴(`gocheokmemorize://`)을 거쳐 AppDelegate 가 바꿔야 했지만,
  TWA 는 이 도메인 주소를 바로 받는다.
- 웹은 고칠 것이 없다 — `app.js` `routeAfterLoad` 의 `?v=`·`?w=` 길이 기기를 가리지 않는다(아이폰용으로 만든 것).
  로그인 전이면 웹이 로그인 화면을 먼저 보이고, `?v=` 는 로그인 없이도 암송 화면이 열린다.
- ⚠️ **실기기에서 꼭 볼 것**: 앱이 **이미 켜져 있을 때** 위젯을 누르면 그 주소로 넘어가는가. 크롬이 기존 화면을
  앞으로 가져오기만 하고 주소를 안 바꾸면 따로 손봐야 한다.

**새로 고침** — 아이폰과 같은 기준
- 이번주 말씀 · 기도문: 다음 한국 자정. 묵상: 다음 자정과 6시간 뒤 중 이른 때(주일 설교가 늦게 올라와도 반나절 안에).
- 안전망으로 시스템 정기 새로 고침(몇 시간마다)을 함께 둔다.
- 정확한 시각 알람은 **쓰지 않는다** — 안드로이드 12+ 에서 따로 권한(`SCHEDULE_EXACT_ALARM`)을 요구하고,
  그러면 데이터 보안·권한 설명이 늘어난다. 절전 중이면 자정에서 몇 분 늦게 바뀔 수 있다.

**실패하면**
- 성공한 응답은 위젯별로 폰(SharedPreferences)에 적어 두고, 통신이 안 되면 **마지막 내용을 그대로** 보이며
  **30분 뒤** 다시 시도한다(아이폰 `fetchWithFallback` 과 같다).
- 처음부터 통신이 안 되면 「말씀을 불러오지 못했습니다」.

**서버** — 고칠 것이 없다. 아이폰이 쓰는 공개 액션 셋(`getWeeklyVerse` · `getTodayMeditation` · `getTodayBlessing`)을
그대로 부른다. 앱 화면과의 일치는 `tests/widget-parity.py` 가 이미 140/140 으로 확인했다.
⚠️ 위젯은 **로그인 없이 보이는 공개 정보만** 다룬다 — `user_id`·개인정보를 보내지도 담지도 않는다(요청에는 액션 이름만).

## ③ 프로젝트 · 두 판 · 비밀

**자리** — 저장소 루트의 `android-app/`(`ios-app/` 옆). Bubblewrap 이 운영 `manifest.json` 으로 뼈대를 만들고,
위젯 코드는 그 안의 따로 묶은 패키지에 둔다. 언어는 Bubblewrap 이 만드는 것과 같은 **Java**(Kotlin 설정을 더하지 않는다).

**두 판**

| | 시험판 | 정식판 |
|---|---|---|
| 앱 이름 | 「성경암송 시험」 | 「성경암송」(지금과 같다 — 옛 APK 로 확인. 「성경말씀 암송」은 스토어 등록 이름) |
| 패키지 | `kr.onlybible.gocheok.memorize.dev` | `kr.onlybible.gocheok.memorize` |
| 서명 | 이 PC 의 시험용(debug) 키 | 업로드 키 |
| 언제 | 지금 — USB 로 친구 폰에 설치 | 9/27 프로덕션 승인 뒤 |

- 시험판은 패키지가 달라 **플레이스토어 앱 옆에 따로 깔린다** — 쓰시던 앱과 테스터 시계를 건드리지 않는다.
- 위젯이 여는 앱은 **자기 패키지**(`getPackageName()`)다 — 시험판 위젯은 시험판을, 정식판 위젯은 정식판을 연다.
- ⚠️ 시험판은 **앱 위에 주소창이 보인다.** 운영 `.well-known/assetlinks.json` 에 정식판(패키지·지문)만 있어서
  도메인 확인이 실패하기 때문이다. 위젯·누르면 가는 곳을 보는 데는 지장이 없으므로 **운영 assetlinks 는 고치지 않는다.**
  주소창 없는 모습은 ④의 비공개 테스트에서 본다.
- 시험판에만 **「이 날짜로 보기」 빌드 값**을 둔다(구절이 가장 긴 16번이 걸린 2026-04-20 · 묵상이 가장 긴 2026-09-13 ·
  기도문이 가장 긴 2026-10-10 — 셋 다 운영 서버로 확인).
  세 액션이 이미 `date` 를 받으므로 위젯이 그 값을 실어 보낸다. 정식판에는 없다.

**비밀** — ⚠️ 이 저장소는 **공개**이고, 사이트 배포(`deploy.yml` 의 `upload-pages-artifact path: "."`)가
저장소 전체를 올리므로 `android-app/` 도 `gocheok.onlybible.kr/android-app/…` 로 나간다.
- 서명 키(`signing.keystore`)와 비밀번호는 **절대 저장소에 넣지 않는다.** 키는 지금 자리
  (`성경암송 - Google Play package - New/`, 이미 git 무시)에 두고, 정식판을 뽑을 때만 git 밖의 설정 파일에서
  경로·비밀번호를 읽는다. `local.properties`·`keystore.properties`·빌드 결과(apk·aab·`build/`)는 `.gitignore` 에 넣는다.

**도구** — 이 PC 에는 Java 8 만 있고 안드로이드 SDK 가 없다. JDK 17 과 SDK 를 저장소 밖 사용자 폴더
(`C:\Users\sewki\.android-tools\`)에 받는다(1~2GB, 한 번). 기존 Java 8 은 그대로 둔다. 폰 설치는 SDK 의 `adb`.
뼈대는 명령줄 `bubblewrap init`(대화형 질문을 던진다) 대신 **`@bubblewrap/core` 를 Node 스크립트로 불러** 만든다
(`android-app/tools/generate.cjs` — 계획 Task 2). 결과물은 같다.
친구 폰은 개발자 옵션 → **USB 디버깅**을 켜 두었다(2026-09-21). PC 에 처음 꽂으면 「이 컴퓨터에서 항상 허용」.

## ④ 실기기 확인 · 올리기

**시험판 확인표**(USB 설치)
1. 위젯 목록에 셋이 「성경암송 시험」 이름으로 나오는가
2. 놓으면 4×2 이고, 그보다 작게는 안 줄어드는가
3. 세로로 늘리면 이번주 말씀이 큰 글씨 모양으로 바뀌는가
4. **가장 긴 글도 안 잘리는가** — 말씀 69자(`2026-04-20`) · 묵상 117자(`2026-09-13`) · 기도문 245자(`2026-10-10` 「순종의 축복」 —
   「우리 가족」을 채운 뒤 길이. 아이폰 설계의 247자는 채우기 전 길이다). 「이 날짜로 보기」로 그날을 띄운다.
5. 누르면 그 화면으로 가는가 — **앱이 꺼진 상태와 켜진 상태 둘 다**
6. 어두운 모드 · 글씨 크기 「아주 크게」
7. 비행기 모드에서 마지막 내용이 남는가
8. 다음 날 아침 새 내용으로 바뀌어 있는가

**9/27 이후 올리는 순서**
1. 프로덕션 신청은 **지금 판 그대로** → 승인. (그 전에는 Play Console 에 아무것도 올리지 않는다.)
2. Play Console 앱 서명 페이지에서 **업로드 키 지문**을 보고, PC 의 두 키(「New」 `3A:17…` / 옛것 `08:D5…`) 중
   어느 것인지 맞춘다. 운영 assetlinks 에는 구글 앱 서명 키(`BE:91…`)와 `3A:17…` 이 올라 있다.
   업로드 키 재설정(CLAUDE.md 다음 작업)을 먼저 하면 그 새 키로 올린다.
3. 지금 올라가 있는 판보다 **versionCode 를 하나 올리고** versionName 도 올려 정식판 aab 를 뽑는다.
4. 먼저 **비공개 테스트 트랙**에 올려 친구 폰의 플레이스토어 앱으로 업데이트해 본다 — 이때 주소창 없이 나오는지,
   로그인·알림이 그대로인지까지 본다. 괜찮으면 **프로덕션으로 승격**.
5. 데이터 보안 양식은 **그대로** — 위젯은 공개 정보만 받고, 서버에 보내는 것은 액션 이름(과 시험판의 날짜)뿐이다.
6. 구글 업데이트 심사(보통 몇 시간~이틀).

**기록** — CLAUDE.md 다음 작업의 「🤖 안드로이드 위젯」 줄을 이 문서를 가리키게 고친다.

### 폰에서 찾아 고친 것(계획에 없던 것)
- **앱 이름은 「성경암송」** — 계획의 「성경말씀 암송」은 스토어 등록 이름이었다. 옛 APK 대조가 건졌다.
- **시험판 설치가 막혔다**(`INSTALL_FAILED_CONFLICTING_PROVIDER`) — 파일 공유 부품 이름을 Bubblewrap 이 정식 패키지로
  만들어 플레이스토어 앱과 겹쳤다. 시험판만 `providerAuthority` 를 `…dev.fileprovider` 로.
- **위젯이 「불러오지 못했습니다」만 떴다** — TWA 는 크롬이 통신해서 **INTERNET 권한이 원래 없었다.** 한 줄 더했다(일반 권한,
  성도님께 묻는 창 없음). ⚠️ 정식판 대조에서 옛 앱과 다른 것은 이제 **판 이름 · 위젯 받이 셋 · INTERNET** 이다.
- **여백이 많다**(친구) — 글씨 상한을 올렸다(묵상·기도문 17→24sp, 말씀 가로형 15→20sp). 제목 14→16sp.
- **바탕을 반투명으로**(친구 결정) — 흰색·짙은 회색을 75%만 칠한다. 아이폰은 바탕을 비치게 할 수 없어 그대로다.
- 이 PC 의 git 이 줄바꿈을 CRLF 로 바꿔 `gradlew` 가 멈출 수 있어 `android-app/.gitattributes` 를 두었다.
