# 나의 말씀 앨범 — 이어 듣기 (2026-08-21)

## 무엇을 만드나

앨범에 모인 완료 구절을 **한 번에 이어서 듣는다.** 전부 듣거나, 몇 개만 골라 듣거나,
구절 대신 그 구절의 **3분요약(설교 MP3)** 만 들을 수도 있다.

## 왜

앨범은 지금 "눈으로 훑고 스스로 점검하는" 화면이다. 손이 바쁠 때(출퇴근·설거지·산책)
쓸 방법이 없다. 귀로 듣는 길을 열면 같은 자료가 두 배로 쓰인다.

## 재료 (이미 있는 것)

| 재료 | 위치 | 비고 |
|---|---|---|
| `speakLong(text, onEnd)` | app.js | 문장 쪼개기 + 크롬 자동정지 방어 + 조각 실패 시 계속 |
| `playSermonAudio(url, onEnd)` | app.js | 3분요약 MP3 `<audio>` 재생 |
| `stopSpeaking()` | app.js | TTS·MP3 모두 정지 |
| `renderAlbum()`의 `list` | app.js | 섞기·미확인 필터가 이미 걸린 **재생 목록** |
| `sermons[].audio` | 설교 API | 앱 26구절 **전부** 3분요약 MP3 보유 (2026-08-21 확인) |

## 화면

### 도구 줄 아래 「재생 줄」

```
👁요절숨김 👁말씀숨김 💡힌트 🔀섞기 🔎미확인      (기존)
▶️ 전부 듣기 (약 8분)   ☑️ 고르기   📄 요약 함께   (신규)
```

「전부 듣기」는 **화면에 보이는 순서 그대로** 읽는다. 섞기·미확인이 걸려 있으면
그 목록이 곧 재생 목록 — 따로 배울 규칙이 없다.

### 「고르기」를 켰을 때만 나타나는 선택

카드마다 두 칸을 따로 고른다. 말씀만 · 요약만 · 둘 다 모두 된다.

```
⬤ 말씀    ○ 📻 3분요약
시편 119:105
주의 말씀은 내 발에 등이요…
```

재생 순서는 카드 순서대로, 한 카드 안에서는 **말씀 → 3분요약**.

### 재생 바 (재생 중에만, 화면 아래 고정)

```
3 / 12 · 시편 119:105          📻 3분요약
⏮   ⏸ 일시정지   ⏭   ✕
ⓘ 아이폰은 화면이 꺼지면 말씀 낭독이 멈춥니다 (3분요약은 이어집니다)
```

읽는 카드는 강조되고 자동으로 따라 스크롤한다.

## 설계 결정

**요약은 TTS가 아니라 MP3.** 아카이브의 Azure 뉴럴 음성이 기계 낭독보다 낫고,
`<audio>`라 화면이 꺼져도 잘 안 끊긴다(TTS는 아이폰에서 바로 멈춘다).

**설교 데이터(1MB)는 필요할 때만 받는다.** 앨범 코드에 이미
"미리 받지 않고 처음 누른 순간에만"이라는 규칙이 있다. 「전부 듣기」(말씀만)는
설교 데이터 없이 바로 되고, 「요약 함께」·「고르기」를 켤 때 비로소 불러온다.

**선택은 저장하지 않는다.** 숨김·힌트·섞기와 같은 규칙 — 앱을 다시 열면 비어 있다
(한 번 들어와 있는 동안은 유지된다). 「요약 함께」 토글만 저장한다(매번 켜기 번거로우니).

**예상 시간을 버튼에 적는다.** 26구절 전부 + 요약이면 1시간이 넘는다. 모르고
누르면 당황한다. 대본 글자수 ÷ 5.5자/초로 어림한다(3분요약 대본 중앙값 989자 ≈ 3분).

**세대 카운터로 중복 진행을 막는다.** `speechSynthesis.cancel()`이 브라우저에 따라
`onend`를 부른다. 이전/다음을 누를 때 두 칸씩 건너뛰지 않도록 재생마다 번호를 매겨
철 지난 콜백은 버린다.

## 하지 않는 것

- **반복 재생**(끝나면 처음부터) — 필요해지면 그때
- **들으면 자동 「확인」 표시** — 「확인」은 *스스로 떠올려 봤다*는 뜻이다.
  듣기만 하고 찍히면 그 의미가 무너진다
- **배속 조절** — 설정의 읽기 속도(`getSpeakRate`)를 그대로 따른다

## 함께 고치는 것

`speakLong`이 `ut.lang = "ko-KR"`로 못 박혀 있어 **영어(NIV) 구절을 한국어 음성으로
읽는다.** 언어를 인자로 받게 한다(기본값 ko-KR이라 기존 호출은 영향 없음).

## 알려진 제약

아이폰에서 화면이 꺼지면 말씀(TTS)은 멈추고 3분요약(MP3)은 이어진다.
브라우저 한계라 앱에서 어쩔 수 없어 재생 바에 그대로 적는다.
