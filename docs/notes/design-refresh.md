# 디자인 개편 (2026-10-12 시작 · 시안 의견 수렴 중)

> **언제 읽나:** 화면 모양(색·글꼴·단추·배치)을 여러 화면에 걸쳐 손볼 때, 시안에 대한 의견을 반영할 때, 「전」 사진이 필요할 때
> ⚠️ 시안은 아직 **고르기 전**이다. 이 문서의 시안 내용을 앱에 그대로 입히지 말 것 — 친구가 하나를 고른 뒤 4단계부터.

## 왜 · 무엇을 · 누가 (친구 2026-10-12)
- **왜:** 읽기 어렵다 · 화면마다 통일성이 없다 · 단추만 계속 더하는 구조라 앞으로 기능을 넣을 자리가 없다(확장성).
- **범위:** 첫 화면과 말씀 암송 흐름 먼저(첫 화면 → 말씀 목록 → 암송 → 말씀 도전 → 나의 말씀 앨범), 그 뒤 전체.
- **의견 수렴:** 친구가 직접 한다.

## 차례 (2026-10-12 합의)
1. 목표·범위 ✅
2. 「전」 기록 ✅ — 아래 「전」 기록
3. 방향 시안 2~3개 ✅ — 의견 수렴 중
4. 하나를 골라 부품 표(단추·카드·목록 줄·완료 창·빈칸)로 다듬기
5. 색·글자에 이름 붙이기 — **겉모습은 그대로**. `screen-sweep --compare` 로 1px 도 안 움직였는지 본다
6. 문을 달고 새 모양 입히기(🧪 시험 참여자 · 설정의 미리보기) — 스킬 `gated-feature`
7. 공개 + 스토어 사진 · `guide/` · 안내 그림 갈아 끼우기. 공개 시기는 가을 동행(~12/5)과 플레이 심사가 끝난 뒤가 성도님께 덜 혼란스럽다

## 시안 — Design 캔버스(비공개)
https://claude.ai/artifact/N4EDhtsDauyD4yE7n6JXM8 — **친구가 「공유」를 눌러야 다른 분이 열 수 있다.**
줄마다 한 화면: 첫 화면 / 말씀 목록 / 암송(2단계 · 카드) / 말씀 도전(+ 완료) / 나의 말씀 앨범. 각 줄 맨 왼쪽이 「지금」 사진이고, 그 왼쪽 회색 쪽지에 「지금」에서 본 문제를 적었다.
- **A 정돈된 목록** — 지금 색(남색·금색·크림)을 두고 정리만. 상자 단추 대신 묶음 목록(아이콘 + 이름 + ›). 글꼴은 고딕 하나, 명조는 말씀 본문에만. 새 기능 = 목록 한 줄.
- **B 말씀이 먼저** — 종이 바탕 · 포도주색 + 금색 · 이번 주 말씀을 크게. 기능은 3칸 타일. 색이 지금과 가장 다르다.
- **C 크게 · 단순하게** — 글씨 한 단계 크게 · 아래 탭 다섯(홈 · 구절 · 함께 · 내 기록 · 전체) · 첫 화면 단추 6개. 구조가 가장 많이 바뀐다.
- **셋 공통:** 이모지 → 선 아이콘(이모지는 기기마다 모양이 다르다) · 떠 있는 「첫 화면으로」 → 위 「‹ 첫 화면」(C 는 탭) · 「미시도」 → 「아직 안 함」 · 앨범 「확인」의 남색 채움 → 초록 표시 · 어두운 모드 짝(각 시안 Tweaks 의 `dark`).
- 암송 · 도전 · 목록 · 앨범 시안은 **눌러 볼 수 있다**(낱말 카드 채우기 · 힌트 · 완료 화면 · 목록 거르기 · 앨범 확인/가리기).
- 캔버스의 진도(1단계 마침 · 다 마침 · 마음에 둠 · 확인)는 **보기 값**이다. 본문은 개발 DB 의 구절.

## 시안이 기존 결정과 다른 곳 — 고르기 전에 볼 것
- **첫 화면 두 단추 고정**(2026-10-11 · 어르신 「자리가 바뀌어 헷갈린다」) — 셋 다 지켰다.
- **색 위계 넷**(`home-screen.md` ⑤) — A · C 는 지켰고, B 는 남색 자리에 포도주색.
- **고정 단추 「첫 화면으로」**(`.home-fab` · `home-screen.md`) — 시안은 위 「‹ 첫 화면」 또는 탭. 고르면 그 문서의 여백 규칙도 함께 걷는다.
- **「반복해서 쓰기」 · 「마음에 둠」**(`memorize-flow.md`) — 처음 시안은 설정(⚙)과 완료 순간으로 옮겼다가 **되돌렸다(친구 지적 2026-10-12)**. 지금 시안은 앱과 같이 3단계 화면에 둘 다 두고, 「마음에 둠」은 완료 칸 안에도 둔다. ⚠️ **「마음에 둠」을 완료 창·완료 화면에만 두면 안 된다** — 「반복해서 쓰기」(암송)·「자동으로 계속 도전」(도전)을 켜면 완료 창·화면이 건너뛰어져 체크할 틈이 없다(앱 renderTestScreen 주석). 도전 시안도 같은 까닭으로 도전 화면에 둔다. 완료 창 **안**에 두는 까닭(Enter 한 번에 지나친다)도 그 문서에 있다.
- **앨범의 「요약 함께」 · 「주간 말씀 · 쉴만한 물가 · 전부」 칩** — 시안엔 안 그렸다(듣기 설정 안으로 옮긴다고 봄). 없애는 게 아니다.
- **문구**(「미시도」 → 「아직 안 함」, 「1단계 완료」 → 「1단계 마침」 등) — 바꿀 때는 스킬 `copy-truth`. 설명서 · 도움말에 같은 말이 있다.
