# 디자인 개편 (2026-10-12 시작 · 시안 의견 수렴 중)

> **언제 읽나:** 화면 모양(색·글꼴·단추·배치)을 여러 화면에 걸쳐 손볼 때, 시안에 대한 의견을 반영할 때, 「전」 사진이 필요할 때
> ⚠️ 시안은 아직 **고르기 전**이다. 이 문서의 시안 내용을 앱에 그대로 입히지 말 것 — 친구가 하나를 고른 뒤 4단계부터.

## 왜 · 무엇을 · 누가 (친구 2026-10-12)
- **왜:** 읽기 어렵다 · 화면마다 통일성이 없다 · 단추만 계속 더하는 구조라 앞으로 기능을 넣을 자리가 없다(확장성).
- **범위:** 첫 화면과 말씀 암송 흐름 먼저(첫 화면 → 말씀 목록 → 암송 → 말씀 도전 → 나의 말씀 앨범), 그 뒤 전체.
- **의견 수렴:** 친구가 직접 한다.

## 차례 (2026-10-12 합의)
1. 목표·범위 ✅
2. 「전」 기록 ✅ — 아래 「전」 기록
3. 방향 시안 2~3개 ✅ — 의견 수렴 중
4. 하나를 골라 부품 표(단추·카드·목록 줄·완료 창·빈칸)로 다듬기
5. 색·글자에 이름 붙이기 — **겉모습은 그대로**. `screen-sweep --compare` 로 1px 도 안 움직였는지 본다
6. 문을 달고 새 모양 입히기(🧪 시험 참여자 · 설정의 미리보기) — 스킬 `gated-feature`
7. 공개 + 스토어 사진 · `guide/` · 안내 그림 갈아 끼우기. 공개 시기는 가을 동행(~12/5)과 플레이 심사가 끝난 뒤가 성도님께 덜 혼란스럽다

## 시안 전체를 고르기 전에 먼저 앱에 넣은 것 (2026-10-12 친구 결정 · 새로 오신 분 부담 덜기)

## 🧪 첫 화면 A안 미리보기 — `?home=a` (2026-10-13 · 친구 「이번 주 말씀 아래를 A안으로」)
- **https://gocheok.onlybible.kr/?home=a** 로 연 기기에서만. `?home=b` 는 B안, `?home=off`(또는 `0`)·「원래 화면으로」는 원래 화면 — 표식(`home-a-preview` · `home-b-preview`)은 늘 하나만 남는다(`readHomePreviewParam`).
- **이번 주 말씀 아래만** 바꾼다 — 위(인사 · 오늘 N회 · 말씀 암송 · 말씀 도전 · 이번 주 말씀)는 원래 그대로. `applyHomeA()`(app.js)가 단추들을 「묶음 제목 + 흰 카드 줄 목록(선 아이콘 칸 · 이름 · ›)」으로 **옮겨 담는다**: 말씀 묵상(내게 주시는 말씀 · 매일 묵상) · 내 기록 · 교회 생활 · 암송 과정(쉴만한 물가 · 내 안에 거하는 말씀 · 네비게이토 · 퀴즈 — 2026-10-13 친구 · 「함께」 바로 위) · 함께(게시판 · 기도문 · 필사) · 교회 사이트 「앱 밖으로 나가요」(아카이브 둘 · ↗ 상자). 「더 보기」는 풀린다. 맨 아래 아이콘 줄은 도구 칸(구절 · 쓰기 · 도움말 / 알림 · 설정 — 6칸 격자로 3 + 2).
