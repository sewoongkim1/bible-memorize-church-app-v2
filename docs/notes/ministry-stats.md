# 📊 사역 통계 (교회 어드민 · 2026-10-06 운영)

> 코드는 교회 어드민 저장소(`c:\Projects\church-admin`). 이 문서는 성경암송 쪽에서 볼 지도다. 설계 `docs/superpowers/specs/2026-10-06-ministry-stats-design.md` · 계획 `docs/superpowers/plans/2026-10-06-ministry-stats.md` · 왜 이렇게 정했나 `docs/analysis/2026-10-06-ministry-stats-options.md`.

## 무엇
- 사역신청 담당(+ 총괄)이 교회 어드민 「📊 사역 통계」에서 17년치(2010~2026) 사역 임명을 **찬양 · 교회학교 · 그 밖**(목양·기관은 따로)으로 갈라, 해마다 봉사자·자리와 계속·돌아옴·처음·나감(옮김·쉼·떠남)을 본다. 계열별·안쪽 나눔·나이·성별·직분·엑셀.
- 이름은 화면에 없다. 사역 이력(`ministry_history`)과 교인명부(`church_people`)를 읽기만 한다 — 성경암송 앱 표는 건드리지 않는다.

## 알아 둘 것
- **부서 이음표**(`ministry_dept_map`): 해마다 달리 적힌 부서 97가지·부서-팀 쌍 541가지를 계열 21·표준 팀 159에 이은 표. 원본은 church-admin `tools/history/dept_lineage_draft.py`(규칙) → `--seed-sql` → SQL 013b. 2027년 명단이 들어와 새 부서·팀이 생기면 「이음표에 없는 쌍」으로 뜬다(화면 「세는 법」 맨 아래).
- **명단이 일부인 해**(`ministry_list_gaps`): 2021년 전체 · 교회학교 2014·2023~2024 · 재정 2022~ — 숫자로 미룬 후보다. 사역 담당에게 확인이 오면 표를 고친다(고치면 church-admin `tools/history/stats_check.py` GAPS 도).
- **사람 열쇠 셋**: 교인(교인ID) · 떠난 분(이름 — 교인명부에 없는 분) · 아직 못 정함(이름+목장). 못 이은 줄을 빼지 않아야 옛 해 유지율이 부풀지 않는다.
- ⚠️ 이름만 보고 부서를 잇지 말 것 — 팀까지 내려가 앞뒤 해 사람 흐름으로 확인한다(세 번 틀렸다).
- 나중: 떠난 분 이름 목록·손으로 합치기/나누기 · 새 부서를 잇는 화면 · 잔존 곡선 · 2027 신청 분석.
