## 사용 설명서 (2026-08-21)
어르신도 혼자 보실 수 있게 **한 화면에 한 가지 · 큰 글씨 · 그림 · 큰 [다음] 단추**.
- **앱 안:** 첫 화면 **❓** → `renderManual`. 목차 14항목(설치 → 알림 → 로그인 → 암송 → 듣기 → 음성 → 앨범 → 순위 → 게시판 → 내게 주시는 말씀 → 매일 묵상 → **쉴만한 물가**(2026-09-11 추가) → 필사 신청 → 글씨 크기) → 누르면 그 항목만 한 화면에. 맨 아래 「자세한 안내」가 기존 `renderHelp`(긴 글·개인정보)로 들어간다 — **첫 화면 단추는 늘리지 않았다.** ①②에는 「📲 지금 만들기」·「🔔 지금 켜기」 실행 단추가 붙어 있다(읽고 딴 화면을 찾아가게 하지 않는다). 그림은 화면 사진이 아니라 단순한 그림 — 사진은 폰마다 다르고 화면이 바뀌면 곧 낡는다.
- **화면으로 따라 하기:** `guide/` (gocheok.onlybible.kr/guide/) — **들어가는 문 두 곳**: ❓ 사용 설명서 **목차 맨 위**, 그리고 **인트로 마지막 장**(처음 설치한 분이 자연스럽게 만나게. 슬라이드 내용은 관리자가 바꾸므로 단추는 슬라이드가 아니라 화면 쪽에 뒀다). 첫 화면 단추는 늘리지 않았다.
  `?s=4`로 특정 걸음을 바로 연다(로비에서 「④번 보세요」 하고 링크로 짚어 주기 좋다). — **실제 앱 화면**을 한 걸음씩 넘겨 보는 페이지. **로그인이 필요 없다**(설치 전에도, 로비에서 QR로도 열린다). 자막을 브라우저 TTS로 읽어 줘 녹음할 사람이 없어도 말로 설명된다(첫 진입은 꺼진 채 시작 — 조용한 자리에서 갑자기 말이 나오면 놀라신다). 화면 그림은 `guide/shots/*.png`이고 **캡처 스크립트로 다시 뽑는다**: index.html에 씨앗 스크립트를 끼운 임시 파일을 로컬 서버로 띄우고 `?go=<렌더함수>`로 원하는 화면을 부른다. ⚠️ 캡처할 때 **fetch를 가로채 전부 로컬 응답으로 답해야 한다** — 그냥 띄우면 login 액션이 운영 users 테이블에 가짜 사람을 만든다. 이름도 실제 성도가 아닌 '홍길동/사랑 1목장'을 쓴다(공개되는 화면이다). 자동 팝업(오늘의 묵상·홍보·공지)은 DOMContentLoaded에서 무력화한다.
- **인쇄물:** `marketing/manual/manual-gen.py` → `사용설명서_A4.pdf`(앞뒤 2쪽). 앞면=「성경말씀 암송 어플 설치방법」(QR·설치·로그인·알림), 뒷면=「성경말씀 암송 어플 설명서」(쓰는 법·부가 기능·필사 신청). 로비 봉사자가 나눠 드린다. 본문 12.5pt·QR 25mm. **판이 넘치는지는 반드시 측정으로 확인**한다 — `1mm = 96/25.4 = 3.7795px` **고정**이지 창 너비에 맞춰 늘어나지 않는다(이걸 헷갈리면 멀쩡한 판을 넘쳤다고 오인한다).
- **최신화 점검 · 중간에 나가기(2026-09-21):** 설명서가 **9/02 첫 화면 정리 이전 배치**를 가리키고 있었다 — 「첫 화면 위쪽 📲·🔔·⚙️」(아이콘 줄은 이제 첫 화면 **맨 아래**이고 📲 자리는 ⌨️ 쓰기/👆 카드 전환이 차지했다) · 「🎤 암송 시작」(실제 「🎤 암송」) · 암송 화면 「💡 힌트」(힌트는 **도전 화면에만** 있고 암송 화면은 「보기」) · 글씨 「큼·아주 큼」(실제 「크게·아주 크게」) · 순위 「이번 주」(기본은 「전일~당일」) · 응원 자격 「오늘 도전」(서버는 암송·도전·복습 **아무거나**) · 필사 신청이 「더 보기」 안으로 들어간 것. `guide/` 자막도 같은 자리를 가리켰다(①⑤⑥⑧⑨, ⑧ 동그라미는 「화면 밝기」를 짚고 있었다 → 「크게」로).
  - **목차는 이제 17항목** — 빠져 있던 셋을 더했다: **👆 카드로 채우기**(참여자 32%가 쓰는데 설명이 없었다) · **🔥 말씀 도전 · 복습**(복습 간격 3일·1주·2주·한 달·두 달 = `REVIEW_INTERVALS`) · **🙏 가정 축복 기도문**(첫 화면 「함께」에 열려 있는데 설명이 없었다).
  - **`when`** — 항목에 조건을 달 수 있다(`manualItems()`). ① 설치는 **이미 앱으로 쓰는 분**(standalone·아이폰 앱)께 빼고, 쉴만한 물가는 첫 화면 단추와 **같은 `psalmVisible()`**로 건다. ⚠️ 번호·「n / 전체」·이전/다음은 모두 걸러진 목록을 따른다 — `MANUAL[i]` 를 직접 쓰지 말 것.
  - **중간에 나가기** — 설명서 목차·항목·자세한 안내에 **아래 고정 「🏠 첫 화면으로」(`.home-fab`)**를 달았다. 위의 ✕ 닫기는 글씨를 키우거나 목차를 내려 읽는 동안 화면 밖에 있었다. ⚠️ **sticky 로 머리를 붙이는 방법은 안 된다** — 이 앱은 `html, body { overflow-x:hidden }` 이라 sticky 가 안 붙는다(`style.css` `.min-acts` 주석). `guide/` 는 아래 조작 줄에 **✕ 닫기**를 더했다 — 아이폰 앱처럼 뒤로 가기 단추가 없는 곳에서는 **아홉 걸음 끝까지 가야만 나올 수 있었다.** 잰 것: 폭 320·390 × 보통·크게·아주 크게·어두운 모드 — 고정 단추 늘 보임, 가로 넘침 0, 끝까지 내렸을 때 마지막 단추와 48px 이상 떨어짐, `guide/` 네 단추 한 줄(320px 포함).
  - 「자세한 안내」(`renderHelp`)의 개인정보 칸이 `privacy/` 와 어긋나 있었다 — **게시판 글·사진**과 **알림 등록 정보**를 수집 항목에 안 적었고, 기록이 「진도와 순위**에만**」 쓰인다고 했다(교구·부서별 합계를 보고 자료로 쓴다). 설정의 개인정보 화면(`renderPrivacyInfo`)에는 「내게 주시는 말씀」 **질문 글**이 빠져 있었다. ⚠️ **셋(공개 방침·도움말·설정 화면)은 늘 같은 것을 말해야 한다.**
  - `guide/shots/manual.png`(⑨) 만 다시 찍었다 — 나머지 사진은 지금 화면과 맞아 그대로 뒀다.
  - ⚠️ **첫 화면·설정의 단추를 옮기거나 이름을 바꾸면 `MANUAL`·`renderHelp`·`guide/index.html` 을 함께 고친다.** 설명서는 단추를 **자리와 이름으로** 가리키므로, 안 고치면 아무 오류 없이 조용히 틀린 말을 한다(이번에 세 주 가까이 그랬다).
- **위젯 안내(2026-09-21):** 설명서에 「🧩 바탕화면에 말씀 두기 (위젯)」 두 장(아이폰 · 안드로이드 — 폰마다 넣는 길이 달라서)을 알림 켜기 다음에 넣었다. **지금은 꺼져 있다.**
  - ⚠️ **켜는 것은 사람이 한다** — `app.js` 의 `WIDGET_GUIDE = { ios: false, android: false }`. 웹은 앱 판 번호를 몰라 아이폰 1.0.1(이번주 말씀 하나)과 1.1.0(셋·잠금 화면)을 못 가른다. 출시 전에 켜면 **아직 없는 위젯을 안내한다.** 아이폰은 App Store 에서 1.1.0 「출시」를 누른 날, 안드로이드는 위젯 판이 플레이스토어에 나간 날 `true` 로 바꾸고 bump → 푸시.
  - 누구에게: 아이폰 장은 `isNativeApp()`(Capacitor) 일 때, 안드로이드 장은 **플레이스토어 앱(TWA)으로 한 번이라도 열린 폰**일 때. TWA 는 앱을 열 때 `document.referrer` 를 `android-app://kr.onlybible.gocheok.memorize…` 로 주는데 그 순간에만 알 수 있어 `localStorage['play-store-app']` 에 적어 둔다(9/21 부터 적기 시작 — 그 뒤 앱을 한 번도 안 연 분은 「모름」이라 안 보인다). 웹·홈 화면 웹앱에는 위젯이 없으니 어느 쪽도 안 보인다. 플레이 앱으로 확인된 폰은 ① 설치 장도 뺀다(`manualInstalled`).
  - 출시 전 문구 확인: **`?preview=widget`** — 두 장이 모두 뜬다.
  - 목록에 뜨는 이름을 그대로 적었다: 아이폰 「고척교회 성경암송」(`CFBundleDisplayName`) · 안드로이드 「성경암송」(`launcherName`), 위젯은 둘 다 「이번주 말씀 · 오늘의 묵상 · 오늘의 축복 기도문」. 잠금 화면은 아이폰의 이번주 말씀만. **앱 쪽 이름을 바꾸면 여기도.**
- **홈 화면에 앱 만들기:** 안드로이드는 `beforeinstallprompt`를 잡아 두어 **📲 한 번이면 크롬이 설치창을 띄운다**. 아이폰 사파리에는 그 API가 없어 공유 시트를 거쳐야 하므로 `renderInstallGuide()`가 **어느 단추인지 그림으로 짚어** 준다(자기 폰 쪽이 펼쳐져 뜬다). **카카오톡 내부 브라우저에서는 어느 폰이든 설치가 안 된다** — 두 안내 모두에 적어 두었다.
