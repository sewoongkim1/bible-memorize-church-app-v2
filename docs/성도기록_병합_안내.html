성도 기록 병합 안내

이름이나 교구·목장이 바뀐 뒤 새 소속으로 이미 사용하여 기록이 두 사용자로 나뉜 경우의 처리 방법입니다.

이전 사용자 A사랑교구 1목장 김세웅
이전 소속에서 쌓인 기록
→
현재 사용자 B화평교구 20목장 김세웅
새 소속에서 이미 사용한 기록
결과: B를 유지하고 A의 기록을 B에 모읍니다. 이전 소속이나 이전 기기에서 접속해도 B의 기록으로 연결됩니다.

DB에서 일어나는 일

  1. users에서는 현재 사용자 B를 유지합니다.
  2. A에 연결된 기록의 user_id를 B로 변경하거나, 겹치는 기록은 아래 기준으로 병합합니다.
  3. 이전 식별 정보는 B의 로그인 별칭으로 저장합니다.
  4. users의 A 행은 삭제합니다.
  5. user_merges에는 A → B 연결, 병합 시점, 당시 프로필과 사유를 보관합니다.

따라서 users에는 B만 남지만, 이전 소속 정보와 이전 사용자 번호는 B로 해석됩니다.

기록별 처리 기준

기록병합 방법
암송·도전 로그모든 행과 기록 시각을 유지하고 B로 이전합니다. 횟수는 합산합니다.
한글·영어 진도같은 구절·언어는 높은 단계를 유지합니다. 마음에 둠은 한쪽이라도 체크했으면 유지합니다.
복습 일정마지막 복습일이 더 최근인 쪽의 상자와 예정일을 유지합니다.
긴 본문 암송완료한 마디를 합치고 한쪽이라도 전체 완료면 완료 상태를 유지합니다.
축복 기도문 조회같은 날짜·기도문은 조회 횟수를 합산합니다.
게시글·답글·필사 신청·알림 기기원래 행을 보존하고 작성자 또는 신청자의 사용자 번호만 B로 변경합니다.
공감·이벤트 참여·순위 응원동일한 반응·참여가 겹치면 한 건만 남깁니다. 병합 뒤 자기 자신에게 한 응원은 제거합니다.
사역·상세 이벤트 신청서로 다른 신청은 이전합니다. 동일 사역팀이나 동일 회차 신청이 양쪽에 있으면 병합을 중단합니다.

관리자 사용 방법

  1. 관리자 허브에서 성도 정보 관리를 엽니다.
  2. 이전 소속의 성도를 검색해 선택합니다.
  3. 현재 사용 중인 이름·소속을 입력하고 사유를 적습니다.
  4. 변경 내용을 확인하고 저장합니다.
  5. 현재 정보의 사용자가 이미 있으면 양쪽 기록 수를 확인합니다.
  6. 동일인 확인 체크 후 같은 성도 확인 후 기록 합치기를 누릅니다.

안전장치

이름이 같다는 이유만으로 자동 병합하지 않습니다. 관리자가 동일인 확인을 해야 하며, 실행 전에는 어떤 기록도 바뀌지 않습니다.

  • 병합은 하나의 트랜잭션으로 실행되어 오류가 나면 전체가 취소됩니다.
  • 새 기능의 미지원 기록이 있으면 삭제하지 않고 병합을 중단합니다.
  • 동일 사역팀 또는 동일 상세 이벤트 신청이 양쪽에 있으면 답변·상태 보존을 위해 중단합니다.
  • 관리자 화면에는 분리 복구 기능이 없으므로 동일인일 때만 실행해야 합니다.
  • 병합 후 이전 소속 정보는 다른 신규 사용자에게 재사용할 수 없습니다.

병합 후 확인

이전 소속과 현재 소속으로 각각 접속해 같은 진도와 복습 기록이 보이는지 확인합니다. 관리자 화면에서 현재 소속으로 다시 검색하면 한 명만 표시됩니다.
