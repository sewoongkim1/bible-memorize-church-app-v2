# go/ — 인쇄물 QR 짧은 주소 (2026-10-28)

인쇄물에 찍는 QR 이 가리키는 주소다. 폴더마다 `index.html` 이 진짜 목적지(유튜브 등)로 넘겨 준다.
QR 은 한 번 뽑으면 못 고치지만 이 쪽은 언제든 고칠 수 있다 — **영상이 아직 없는 날도 QR 을 미리 찍어 둘 수 있다.**

| 주소 | 만드는 곳 | 무엇 |
|---|---|---|
| `go/thanks1/` ~ `go/thanks6/` | `자료/booklet/generate_thanks.py` ← `thanks2026.json` 의 `video`·`start` | 2026 추수감사 특별새벽기도회 1~6일차 설교 영상(소책자 차례의 QR) |

- ⚠️ **손으로 고치지 말고 만드는 곳에서 다시 만든다** — 다음에 생성기를 돌리면 덮어쓴다.
  영상이 생기면 그 날의 `video`(영상 ID)·`start`(설교 시작 초)를 적고 생성기를 돌린 뒤 커밋·푸시.
- 영상이 없는 날의 쪽은 넘기지 않고 「아직 연결되지 않았습니다 · 고척교회 유튜브 열기」를 보여 준다.
- ⚠️ QR 에는 끝 「/」 까지 넣는다 — 없으면 GitHub Pages 가 `/go/thanks1` → `/go/thanks1/` 로 한 번 더 돌린다
  (서비스워커가 화면 요청을 다시 받아 넘기는 자리라 되돌림을 한 번이라도 덜 거치게).
- ⚠️ 이 폴더가 `tools/site.py` 의 `SITE_DIRS` 에 있어야 사이트로 나간다. 이 README 는 `.md` 라 안 나간다.
- 새 인쇄물이 이 폴더를 쓰면 위 표에 한 줄 더한다(이름이 겹치지 않게 — 다음 해 추수감사는 `thanks27-1` 꼴로).
