# 성경 필사노트(가로형) 만들기

> 성경 한 권(또는 한 장)을 고르면, **왼쪽엔 성경 본문, 오른쪽엔 따라 쓸 줄**이 있는
> A4 가로 인쇄용 파일을 만들어 줍니다. 크롬으로 열어 바로 인쇄하면 됩니다.

---

## 1. 이게 뭐 하는 도구인가요?

필사노트를 손으로 만든다고 생각해 보세요.

1. 왼쪽 칸에 성경 구절을 옮겨 적습니다.
2. 그 구절이 **세 줄**을 차지했다면, 오른쪽 칸에 자를 대고 **세 줄**을 긋습니다.
3. 종이가 차면 다음 장으로 넘어갑니다. 한 구절이 두 장에 걸쳐 잘리지 않게요.

이 도구가 이 일을 대신합니다. 구절이 몇 줄이 될지 **눈대중으로 세지 않고, 크롬에 실제로 찍어 본 뒤
자로 재듯 재서** 그만큼 줄을 긋습니다. 그래서 글씨 크기나 칸 넓이를 바꿔도 줄 수가 늘 딱 맞습니다.

만들어지는 것은 **HTML 파일 하나**입니다. 웹 페이지 파일이라 크롬으로 열어 `Ctrl+P` 로 인쇄합니다.

인쇄 성경처럼 찍습니다. 장이 시작하는 자리에는 **왼쪽에 「1장」**(시편은 **「1편」**)이, 시편의 권이 바뀌는 편
위에는 **가운데에 「제일권」** 같은 권 제목이 찍힙니다. 오른쪽 필사 칸에도 같은 자리에 같은 글이 들어가,
양쪽 줄이 늘 나란히 갑니다.

| 준비물 | 이 PC | 다른 PC에서 쓰려면 |
|---|---|---|
| 파이썬(Python) | 설치되어 있음 | python.org 에서 설치 |

⚠️ `bible/` 폴더는 인터넷 저장소(GitHub)에는 없습니다. 개역개정은 대한성서공회 저작물이라 공개된 곳에 올리지 않습니다.

## 3. 만들기 — 세 걸음

### ① 명령 창 열기

탐색기에서 `bible-note` 폴더를 엽니다 → 위쪽 **주소창을 누르고 `cmd` 라고 쓴 뒤 Enter** →
까만 명령 창이 그 폴더에서 열립니다.

### ② 만들기

책 이름을 넣어 한 줄 칩니다.

```
python generate.py 유다서
python generate.py 요한복음 --chapter 1
python generate.py 시편 --chapter 1
```

- `--chapter 1` 은 「1장만」(시편은 「1편만」)이라는 뜻입니다. 빼면 그 책 전체를 만듭니다(장이 바뀌면 새 쪽에서 시작).
- 끝나면 이렇게 나옵니다: `완료: 유다서.html (5쪽 · 25절)`
- 파일은 `bible-note` 폴더에 생깁니다(`유다서.html`, `요한복음_1장.html`, `시편_1편.html`).
- 바탕화면에 바로 만들고 싶으면: `python generate.py 유다서 --out C:\Users\sewki\Desktop\유다서.html`
  (서체 폴더 `fonts` 도 바탕화면에 함께 복사됩니다)

> 💡 Git Bash 를 쓰신다면 명령 앞에 `PYTHONIOENCODING=utf-8 ` 을 붙이세요. 안 그러면 한글이 깨집니다.
> 까만 명령 창(cmd)에서는 붙이지 않아도 됩니다.

### ③ 확인하고 인쇄하기

먼저 확인합니다(1분쯤 걸립니다).

```
python verify.py 유다서.html
```

`모두 통과했습니다.` 가 나오면 줄 수 · 줄 맞춤 · 쪽 나눔 · A4 가로 크기가 모두 맞는 것입니다.

그다음 `유다서.html` 을 **크롬으로 열고 `Ctrl+P`**:

| 항목 | 고를 것 |
|---|---|
| 대상 | 쓰시는 프린터 |
| 용지 크기 | A4 |
| 레이아웃 | 가로 — 저절로 잡힙니다 |
| 여백 | 기본값 |
| 배율 | 기본값(100) — **「페이지에 맞춤」을 켜지 마세요.** 줄이 자로 잰 크기보다 작아집니다 |
| 머리글과 바닥글(브라우저) | 끄기 — 주소·날짜가 찍히지 않게 |
| 양면 | 왼쪽 긴 변에 와이어를 끼울 거라면 **「짧은 쪽으로 넘기기」** — 처음엔 **한 장만** 뽑아 뒷면 방향을 확인하세요 |

## 4. 원문 파일 모양

개역개정은 이미 `bible/` 에 있어 **준비할 것이 없습니다.** 새번역·쉬운성경·영어 성경 등을 넣으시거나, 원문이 어떻게
생겼는지 궁금하실 때 읽으세요.

**파일 하나 = 책 한 권**, 이름은 `구분-순번책이름.txt` 입니다(구분: 1 구약 · 2 신약).

```
2-26유다서.txt
```

명령에 쓰는 이름은 파일 이름의 **책 이름 부분과 똑같아야** 합니다(`유다서`).

**한 줄에 한 절**, 모양은 `약자장:절 <소제목> 본문` 입니다.

```
유1:1 <인사> 예수 그리스도의 종이요 야고보의 형제인 유다는 …
유1:2 긍휼과 평강과 사랑이 너희에게 더욱 많을지어다
Jude1:3 Dear friends, although I was very eager to write to you …
```

- **약자**는 숫자로 시작하지만 않으면 무엇이든 됩니다(`유`, `Jude`, `요일` …). `1John1:1` 처럼 숫자로 시작하면 읽지 못합니다.
- **소제목**은 없어도 됩니다. 넣으려면 절 번호 바로 뒤에 `< >` 로 감쌉니다.
- **빈 줄**은 그냥 건너뜁니다.
- **저장 방식**: 메모장의 기본(UTF-8)이든 ANSI 든 둘 다 읽습니다.

### 본보기 파일

`bible-note\_샘플\` 폴더에 개역개정 원문을 그대로 옮긴 본보기가 있습니다. 메모장으로 열어 모양을 보세요.

| 파일 | 담은 곳 | 볼 수 있는 것 |
|---|---|---|
| `_샘플\1-19시편.txt` | 시편 1편 | 권 제목 줄(`시1:제일권`) |
| `_샘플\2-04요한복음.txt` | 요한복음 1장 | 소제목, 괄호가 든 긴 소제목 |
| `_샘플\2-26유다서.txt` | 유다서 전체 | 한 권 전체, 소제목 여럿 |
| `_샘플\특별한_줄\2-04요한복음.txt` | 요한복음 12장 | 절이 두 줄로 나뉜 줄 |
| `_샘플\특별한_줄\2-06로마서.txt` | 로마서 9장 | 두 절이 합쳐진 줄(`롬9:1-2`) |

본보기는 모양을 보여 주려는 것입니다. 도구는 `bible\` 폴더에서만 원문을 찾습니다.
(`_샘플` 폴더는 인터넷 저장소에 올라가지 않습니다 — 개역개정 본문이라서요.)

### 이런 줄도 그대로 찍습니다

원문에는 「한 줄에 한 절」에서 벗어난 줄이 세 가지 있습니다. 인쇄 성경처럼 찍으니 **고치지 않아도 됩니다.**

| 줄 모양 | 예 | 이렇게 찍힙니다 |
|---|---|---|
| 권 제목 | `시1:제일권` | 그 편 첫 절 위, **가운데**에 「제일권」 → 그 아래 왼쪽에 「1편」 |
| 절이 두 줄로 나뉜 줄 | `요12:예수께서 <그들이 예수를 믿지 아니하다> 이 말씀을 하시고 …` | 앞 절(36절)에 이어 **번호 없이**. 소제목이 있으면 그 줄을 먼저 찍고, 그 아래 「예수께서 이 말씀을 하시고 …」 |
| 두 절이 합쳐진 줄 | `롬9:1-2 …` | 번호를 **「1-2.」** 로 찍고 한 절처럼 다룹니다 |

개역개정에는 권 제목 5곳(시편 1 · 42 · 73 · 90 · 107편), 나뉜 줄 45곳, 합쳐진 절 11곳이 있습니다.

⚠️ **이런 줄은 멈춥니다** — 틀린 채 인쇄되지 않게 일부러 그렇게 했습니다. 몇 번째 줄인지 알려 줍니다.

| 멈추는 줄 | 할 일 |
|---|---|
| `약자장:` 으로 시작하지 않는 줄(예: 본문만 덩그러니 있는 줄) | 앞에 `유1:3` 처럼 붙이거나 앞 줄에 이어 붙이세요 |
| `유1:` 처럼 번호 뒤에 아무것도 없는 줄 | 지우세요 |
| 나뉜 줄인데 바로 앞에 같은 장의 절이 없다 | 앞 절이 빠지지 않았는지 보세요 |
| 권 제목 다음 줄이 같은 장의 절이 아니다 · 권 제목 뒤에 절이 없다 | 권 제목 자리를 확인하세요 |

## 5. 모양 바꾸기

`bible-note/render.py` 를 메모장으로 열면 **맨 위에 설정**이 모여 있습니다. 숫자·글자만 바꾸고 저장하세요.

| 설정 | 지금 값 | 뜻 |
|---|---|---|
| `FONT_PT` | `12` | 성경 본문 글씨 크기(pt). 16 정도까지 무난합니다 |
| `LINE_MM` | `9.5` | 줄 간격(mm) = 손글씨 칸 높이. 한 쪽 줄 수가 따라 바뀝니다(9.5 → 17줄, 10 → 16줄) |
| `ORIG_PCT` | `50` | 왼쪽 원문 칸의 비율(%). 50 이면 반반 |
| `LETTER_SPACING_EM` | `0` | 본문 자간. 한글은 보통 -0.03 ~ 0.05 |
| `HEADER_PT` | `11` | 머리글(책·절 범위 · 날짜 칸) 글씨 크기 |
| `HEADER_FONT_URL` | `{}` | 머리글 서체. 비우면 본문 서체 |
| `FOOTER_PT` | `9` | 바닥글 글씨 크기 |
| `FOOTER_FONT_URL` | `{}` | 바닥글 서체. 비우면 본문 서체. 쓰는 법은 머리글 서체와 똑같습니다 |
| `FOOTER_LEFT` | `'God is Love'` | 바닥글 왼쪽 |
| `FOOTER_CENTER` | `'주의 말씀은 내 발에 등이요 내 길에 빛이니이다'` | 바닥글 가운데(홀수 쪽) |
| `FOOTER_CENTER_EVEN` | `'Your word is a lamp to my feet and a light for my path.'` | 바닥글 가운데(짝수 쪽). `''` 로 비우면 홀수 쪽과 같습니다 |
| `FOOTER_RIGHT` | `'{page} / {total}'` | 바닥글 오른쪽. `{page}` 는 쪽 번호, `{total}` 은 전체 쪽 수로 바뀝니다 |

- 바닥글 칸을 비우려면 `''` 로 두세요.
- **고친 뒤에는 꼭 ② 다시 만들기 → ③ 확인** 을 하세요. 옷 치수를 바꾸면 다시 재단해야 하는 것과 같습니다.
  이 도구는 다시 만들 때마다 줄 수를 새로 재므로 필사줄이 저절로 맞춰집니다.

### 내 PC에 있는 서체를 머리글·바닥글에 쓰려면

1. 서체 파일을 찾습니다 — `C:\Windows\Fonts` 또는 직접 설치한 서체는
   `C:\Users\sewki\AppData\Local\Microsoft\Windows\Fonts` (예: `BMJUA_ttf.ttf`)
2. 그 파일을 `bible-note\fonts\` 에 복사합니다.
3. `HEADER_FONT_URL = {'fonts/BMJUA_ttf.ttf': ''}` 처럼 적습니다(파일이 이미 있으니 주소는 비워 둡니다).
   바닥글도 같은 방법으로 `FOOTER_FONT_URL = {'fonts/BMJUA_ttf.ttf': ''}`. 머리글과 같은 파일이어도 됩니다.

- 파일 이름 앞에 꼭 `fonts/` 를 붙이세요. 도구는 `fonts` 폴더 안의 파일만 HTML 옆으로 함께 옮깁니다.
- 머리글·바닥글 서체는 **각각 한 파일만** 적습니다.
- `.ttf` · `.otf` · `.woff` · `.woff2` 는 됩니다. `.ttc`(바탕체처럼 여러 서체를 묶은 파일)는 브라우저가 읽지 못해 멈춥니다.
- 유료 서체는 HTML 과 함께 남에게 줄 때 약관을 확인하세요.

### 본문 서체를 바꾸려면

`render.py` 의 `FONT_URL`(받아 올 주소) 과 그 아래 `@font-face` 두 줄의 `src`(파일 이름)를 **함께** 바꿉니다.
한 곳만 바꾸면 서체가 조용히 기본 명조로 바뀝니다. 한글이 다 들어 있는 서체여야 합니다.

## 6. 멈췄을 때

빨간 글씨가 길게 나와도 놀라지 마세요. **맨 아래 한 줄**이 이유입니다.

| 이렇게 나오면 | 뜻 | 할 일 |
|---|---|---|
| `시편 12번째 줄: 장·절 번호가 없는 줄이라…` 처럼 `…번째 줄:` | 원문에 읽을 수 없는 줄 | 4번 「이런 줄은 멈춥니다」 표대로 원문을 고치세요 |
| `bible/ 에서 "…"를 못 찾았습니다` | 책 이름이 파일 이름과 다름 | 비슷한 이름을 보여 주니 그대로 치세요 |
| `서체를 받지 못했습니다` | 인터넷이 안 됨 | 인터넷이 되는 곳에서 한 번 돌리세요 |
| `서체 파일이 없습니다` | 주소를 비운 내 PC 서체가 `fonts` 에 없음 | 서체 파일을 `bible-note\fonts\` 에 복사하세요 |
| `.ttc(여러 서체를 묶은 파일)는 브라우저가 읽지 못합니다` | `.ttc` 서체를 적음 | `.ttf` · `.otf` 서체를 쓰세요 |
| `서체는 한 벌만 지정할 수 있습니다` | 머리글(또는 바닥글) 서체에 파일을 둘 이상 적음 | 하나만 남기세요 |
| `크롬을 못 찾았습니다` | 크롬이 없음 | 크롬을 설치하세요 |
| `…절이 N줄이라 한 쪽에 들어가지 않습니다` | 절 하나가 한 쪽보다 김 | 글씨를 줄이거나 원문 칸을 넓히세요 |
| `저장소 안인데 커밋에서 무시되지 않는 자리` | 공개 저장소에 올라갈 수 있는 곳에 저장하려 함 | `--out` 을 바탕화면 등으로 |

`verify.py` 가 `문제 발견:` 을 내면:

| 문제 | 뜻 |
|---|---|
| `ORIG_OVERFLOW` · `WRITE_OVERFLOW` | 본문이나 필사줄이 칸을 넘쳤습니다 |
| `LINE_MISMATCH` · `ALIGN_MISMATCH` · `GROUP_COUNT_MISMATCH` | 필사줄 수나 높이가 원문과 어긋났습니다 — 다시 만들어 보고, 그래도면 알려 주세요 |
| `BLOCK_…_MISMATCH` · `BLOCK_OVERFLOW` | 권 제목·장 표시·소제목 칸이 양쪽에서 어긋났습니다 — 다시 만들어 보고, 그래도면 알려 주세요 |
| `HEADER_OVERFLOW` · `FOOTER_OVERFLOW` | 머리글·바닥글 글이 칸을 넘쳤습니다 — 글을 줄이거나 글씨 크기를 줄이세요 |
| `FONT_NOT_LOADED` | 서체가 안 불렸습니다 — `fonts` 폴더가 HTML 옆에 있는지 보세요 |
| `PRINT_PAGES` · `PRINT_SIZE` | 인쇄했을 때 쪽 수나 용지 크기가 다릅니다 |
| `PRINT_FAILED` | 크롬이 PDF 를 만들지 못했습니다 — 가끔 한 번 헛돕니다. 그대로 다시 돌려 보세요 |
| `PRINT_CHECK_UNAVAILABLE` | 인쇄 확인에 쓰는 꾸러미가 없습니다 — `pip install pymupdf` 한 번 |

확인은 **한 번에 하나씩** 돌리세요. 같은 폴더에서 둘을 동시에 돌리면 서로의 임시 파일을 읽어 결과가 틀릴 수 있습니다.

화면 맨 위에 **붉은 띠**(서체를 불러오지 못했습니다)가 보이면, HTML 을 옮기면서 `fonts` 폴더를 빠뜨린 것입니다.
HTML 과 `fonts` 폴더는 **늘 함께** 옮기세요.

## 7. 꼭 지킬 것

- **만든 HTML 은 인터넷 저장소에 올리지 않습니다.** 개역개정 본문이 통째로 들어 있기 때문입니다.
  `bible-note` 안에 만들면 저절로 빠지게 해 두었고, 올라갈 수 있는 곳에 저장하려 하면 도구가 멈춥니다.
- HTML 을 다른 곳으로 옮길 때는 **`fonts` 폴더도 함께**.
- 처음 인쇄할 때는 **한 장만** 뽑아 가로 방향 · 양면 방향 · 와이어 자리를 확인하세요.
