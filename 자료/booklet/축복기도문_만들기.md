# 가정 축복 기도문 핸드북 만들기

A5 · 한 편 한 쪽 · 104편을 52편씩 두 권.

## 0. 제일 쉬운 길 — 배치 파일 두 개 (2026-09-04)

| 더블클릭 | 하는 일 |
|---|---|
| **`뽑기.bat`** | 한 분 몫으로 **여섯 판**(컬러/흑백 × 웹폰트/PC서체 × A5/A4)을 한 번에. 모양을 볼 때. |
| **`명단뽑기.bat`** | **`명단.txt`** 에 적힌 분들 몫을 한 번에. **PDF 까지 자동으로** 굽습니다. |

`명단.txt` 는 한 줄에 한 분씩입니다(`#` 로 시작하는 줄은 건너뜁니다).

```
홍길동
김철수
이영희
```

`명단뽑기.bat` 를 메모장으로 열면 맨 위에서 모양을 고를 수 있습니다.

```bat
set THEME=bw      rem  gold(컬러) teal plum bw(흑백·표지만 컬러)
set FONT=pc       rem  pc(이 PC 서체) web(웹폰트)
set SIZE=a5       rem  a5(소책자) a4(큰글씨판)
set PDF=1         rem  1이면 PDF 까지 · 0이면 HTML 만
set OUT=출력       rem  내보낼 폴더
```

나오는 파일은 `출력\축복기도문_1권_김세웅_bw_pc.pdf` 처럼 **성함이 들어갑니다**
(안 그러면 다음 분이 앞 분 파일을 덮어씁니다).

⚠️ **PDF 는 한 분에 10초쯤** 걸립니다(두 권). 100분이면 20분쯤 걸리니 켜 두고 기다리세요.
⚠️ PDF 에는 **서체가 박히므로** 인쇄소에 넘겨도 이 PC 와 똑같이 나옵니다.
⚠️ 돌린 뒤 화면에 뜨는 **조사 목록**(`김하늘 로` / `김세웅 으로`)을 한 번 훑어 주세요 —
   ㄹ 받침이 함정입니다(김하늘**로** ○ / 김하늘**으로** ×).

## 1. 그냥 뽑기

```
cd booklet
python generate_blessing.py 김세웅
```

`축복기도문_1권.html` · `축복기도문_2권.html` 이 나옵니다.
브라우저로 열어 **인쇄 → PDF로 저장**(용지 A5 · 여백 없음 · 배경 그래픽 켜기).

이름 자리를 그대로 두려면 이름을 빼고 `python generate_blessing.py` — 「홍길동」이 들어갑니다.

## 2. 몇 장만 보기

```
python generate_blessing.py 김세웅 --sample 3
```

`축복기도문_견본.html` — 앞에서 3편만, 표지·차례 없이. 손에 쥐어 볼 때 씁니다.

## 3. 줄 나누는 곳을 손으로 고치기

기도문을 어디서 줄바꿈할지 자동으로 정하지만, **마음에 안 들면 손으로 고칠 수 있습니다.**

### ① 지금 나뉜 대로 파일로 뽑는다

```
python generate_blessing.py --export
```

`줄나눔.txt` 가 생깁니다. 메모장으로 열면 이렇습니다.

```
=== 1 창조의 축복 (창세기 1:28-29)
하나님,
{이름}에게 복을 주시며
{이름}에게 말씀하여 주옵소서.
{이름}{이} 생육하고
...
```

### ② 고친다

- **여기 한 줄이 인쇄되는 한 줄**입니다. 나누려면 엔터, 붙이려면 한 줄로 합치세요.
- `{이름}` 은 인쇄할 때 성함으로 바뀝니다. **지우지 마세요.**
  `{이}` `{을}` `{은}` `{과}` `{으로}` 도 조사라 그대로 둡니다.
- `=== 3 이삭의 축복` 줄은 **건드리지 마세요**(어느 편인지 표시).
- 맺음말(예수님의 이름으로 축복하며 기도합니다. 아멘!)은 자동으로 붙으니 쓰지 않습니다.

### ③ 다시 뽑는다

```
python generate_blessing.py 김세웅
```

**줄나눔.txt 가 있으면 그 파일이 이깁니다.** 자동으로 나눈 것은 무시됩니다.

> 자동으로 돌리고 싶으면 `줄나눔.txt` 를 지우거나 이름을 바꿔 두세요.

### ④ 글자를 잘못 건드리면 알려 줍니다

돌릴 때마다 원문과 대조합니다.

```
!! 원문과 다른 편이 있습니다 — 글자가 지워졌거나 더해졌습니다:
   1번 창조의 축복
   그 편은 파일 내용 그대로 인쇄됩니다. 확인해 주세요.
```

⚠️ **막지는 않습니다** — 일부러 고치실 수도 있으니까요. 다만 조용히 지나가지는 않습니다.

## 4. ⚠️ 줄을 고친 뒤에는 넘치는 쪽을 다시 봐야 합니다

**한 편은 인쇄되는 줄로 14pt 12줄까지** 들어갑니다(13pt 13줄 · 12pt 14줄).
⚠️ **파일의 한 줄이 곧 인쇄 한 줄은 아닙니다** — 14pt 에서 한 줄이 **23자**를 넘으면
브라우저가 접어 두 줄이 됩니다(13pt 25자 · 12pt 27자). 이름 자리는 1.12배로 커지니
이름이 두 번 들어간 줄은 두어 자 짧게 잡으세요.

줄을 더 늘리면 아래 **축복노트**가 먼저 줄어들고, **12mm 아래로 얕아지면 그 쪽에서는
축복노트가 통째로 빠집니다**(상자 안 여백(5mm)을 빼면 「축복노트」 라벨 하나도 못 들어가는
크기 — 6mm대와 15mm대 사이에 뚜렷한 틈이 있어 그 가운데를 문턱으로 잡았습니다, 2026-09-04).
축복노트는 **상한(70mm)도 있습니다** — 짧은 편이 상자를 페이지 절반 가까이 차지해
「미완성처럼 보인다」는 지적이 있어서입니다.
**제목·기도문은 늘 위로 붙고**(2026-09-04), 상자는 `margin-top:auto` 로 **아래에 붙습니다** —
그래서 상자 아랫변은 어느 쪽에서나 꼬리말에서 같은 거리입니다. 상한을 넘는 몫은
기도문과 상자 **사이**에 남습니다.

> ⚠️ 한때 기도문 위에 빈 칸(`.b-gap`)을 두어 짧은 편을 아래로 내려 균형을 잡으려 했다가
> **되돌렸습니다.** 실제로 뽑아 보니 제목 아래가 휑해 「위가 비었다」는 인상이 더 컸습니다.
그래도 넘치면 글씨를 한 단계 내리는 목록이 코드 안에 있습니다(`SMALL`, 지금은 **비어 있습니다**
— 온 책이 예외 없이 14pt 입니다).
그 목록은 **브라우저로 재서 얻은 것**이라, 줄나눔을 고치면 틀어집니다.

재는 법 — 만든 HTML 을 브라우저에서 열고 F12 콘솔에 붙여 넣으세요.

```js
var bad = [];
document.querySelectorAll(".page").forEach(function (p, i) {
  if (p.scrollHeight - p.clientHeight > 1) bad.push(i - 4);   // 편 번호(2권은 +52)
});
console.log("넘치는 편:", bad.join(", ") || "없음");
```

나온 번호를 `generate_blessing.py` 의 `SMALL` 에 `번호: 'p13'` 으로 더하면 됩니다
(13pt 로도 넘치면 `'p12'`).

> ⚠️ 꼬리말은 `position:absolute` 라 자리를 차지하지 않습니다 — **쪽 아래 여백이 꼬리말
> 높이(13mm)보다 얕으면 축복노트 선과 겹칩니다.** 2026-09-04 에 실제로 2.05mm 겹쳐 있었고,
> 아래 여백을 14mm 로 올려 2.15mm 틈을 두었습니다. 꼬리말 글줄을 늘리면 여기부터 다시 재세요.

> 2026-09-04 에 열 편이던 목록이 **한 편으로 줄었습니다.** 축복노트가 18mm 로 버티지 않고
> 필요하면 통째로 빠지게 되어, 아홉 편이 14pt 로 돌아왔습니다.

## 6. 다른 느낌으로 · 큰글씨판 · 인쇄용 2단 (2026-09-04)

```
python generate_blessing.py 김세웅 --theme teal --size a4 --2up
```

| 옵션 | 값 | 뜻 |
|---|---|---|
| `--theme` | `gold`(기본) · `teal` · `plum` | **색**만 바꿉니다(서체와 별개 축). 본문 글자색·테두리·회색 라벨은 **테마와 무관하게 고정**입니다 — 가독성은 취향보다 먼저입니다. |
| `--font` | `web`(기본) · `pc` | **서체**를 바꿉니다. `web` = 웹폰트(나눔명조·본고딕, 어느 컴퓨터에서나 같게 보임). `pc` = **이 컴퓨터에 깔린 서체** — 본문 `학교안심 둥근미소 TTF R` · 제목 `프리젠테이션 8 ExtraBold` · 머리꼬리 `프리젠테이션 7 Bold`. |
| `--size` | `a5`(기본) · `a4` | `a4` 는 **어르신 큰글씨판**입니다. 한 쪽에 한 편은 같고, 판·글씨·여백을 **√2배(A4/A5 비)** 로 그대로 키웁니다 — 새로 값을 정하지 않고 이미 실측으로 다듬어진 A5 비례를 키운 것뿐입니다. |
| `--2up` | (a5 전용) | **인쇄용** — A4 가로 한 장에 소책자 두 쪽을 나란히 찍습니다(가운데 옅은 점선이 자르는 자리). 접어서 제본하는 순서가 아니라 **읽는 순서 그대로** 두 쪽씩입니다 — 집 프린터로 뽑아 반으로 잘라 쓰는 용도입니다. |

파일 이름에 옵션이 붙습니다 — `축복기도문_1권_teal_A4.html` 처럼. 기본값(gold·a5)만 지금까지의
`축복기도문_1권.html` 그대로입니다(기존 안내·링크가 안 깨집니다).

⚠️ **테마를 늘리려면** `THEMES` 사전에 한 줄만 더하면 됩니다 — CSS 는 `:root` 변수(`--accent`
`--accent-ink` `--accent-light` `--deep`)를 참조할 뿐 테마마다 다시 쓰지 않습니다.
**서체를 늘리려면** `FONTS` 사전에 한 줄(`body` · `title` · `head`)을 더합니다.

⚠️ **서체 이름은 「패밀리 이름」이라야 합니다.** 윈도우 글꼴 목록에 보이는 이름(`학교안심 둥근미소
TTF R`, `프리젠테이션 8 ExtraBold`)을 그대로 쓰면 크롬이 못 알아듣고 **조용히 다른 서체로
바꿔 버립니다.** 실측으로 확인한 올바른 이름은 이렇습니다.

| 윈도우에서 보이는 이름 | CSS 에 써야 하는 이름 |
|---|---|
| 학교안심 둥근미소 TTF R | `Hakgyoansim Dunggeunmiso TTF` (굵기 normal = R, bold = B) |
| 프리젠테이션 8 ExtraBold | `Freesentation 8` |
| 프리젠테이션 7 Bold | `Freesentation 7` |

이름을 찾는 법 — 파워셸에서:
```powershell
Add-Type -AssemblyName System.Drawing
(New-Object System.Drawing.Text.InstalledFontCollection).Families | Select-Object -ExpandProperty Name
```
그리고 **먹히는지 반드시 확인**하세요. `--font pc` 로 만든 HTML 을 열면, 서체가 없는 컴퓨터에서는
화면 위에 빨간 띠로 알려 줍니다(인쇄에는 안 나옵니다).

⚠️ **`pc` 서체는 그 서체가 깔린 컴퓨터에서만 제대로 보입니다.** 다만 **PDF 로 저장하면 서체가
파일에 박히므로**, 그 PDF 는 인쇄소든 다른 분 컴퓨터든 똑같이 보입니다 — 넘길 때는 PDF 로 넘기세요.
⚠️ **큰글씨판은 실측을 다시 하지 않습니다** — A5 값을 `A4_SCALE`(√2)로 그대로 곱합니다. 판형을
셋 이상으로 늘리려면(예: A3) 이 배율 대신 다시 브라우저로 재는 편이 안전합니다(A4/A5 처럼
가로세로 비가 서로 같은 판끼리만 한 배율로 안전하게 커집니다).

설계 배경은 `docs/superpowers/specs/2026-09-03-blessing-handbook-design.md`.
