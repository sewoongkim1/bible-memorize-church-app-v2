# 기독교 고전과 함께하는 전교인 필사 — 만들기

A5 소책자 · 44쪽 · **A4 11장 중철**(포개 반 접고 가운데 스테이플).
펼치면 **왼쪽이 고전, 오른쪽이 따라 쓰기**(왼쪽을 그대로 비춘다).

## 1. 그냥 뽑기

```
cd booklet
python generate_classics.py --pdf --booklet
```

세 파일이 나옵니다.

| 파일 | 쓸 곳 |
|---|---|
| `기독교고전_전교인필사_A5_9.5(V1.0).html` | 브라우저로 열어 모양 확인 |
| `기독교고전_전교인필사_A5_9.5(V1.0).pdf` | **A5 44쪽 순서판** — 인쇄소에 넘기거나 화면으로 검토 |
| `기독교고전_전교인필사_A5_9.5(V1.0)_중철A4.pdf` | **A4 가로 22면** — 집·교회 프린터로 뽑아 접을 때 |

**이름에 줄 간격과 판이 들어갑니다**(`9.5` = 줄 간격 · `V1.0` = 판).
간격을 바꿔 여러 벌을 뽑아도 서로 덮어쓰지 않고, 인쇄본을 받아 들었을 때 어느 값으로
뽑은 것인지 이름만 봐도 압니다. **판을 올릴 때는 `generate_classics.py` 의 `BOOK_VER`
한 줄만** 고치세요. 같은 값이 **뒷장 맨 아래에도 아주 옅게 인쇄**됩니다
(`V1.0 · 줄 9.5mm`) — 인쇄본만 받아 들어도 어느 판인지 알 수 있게.

## 2. 집 프린터로 접어 만들기

`_중철A4.pdf` 를 **A4 가로 · 양면(짧은 쪽으로 넘김) · 실제 크기(100%)** 로 인쇄합니다.

⚠️ **「페이지에 맞춤」을 끄세요.** 켜면 살짝 줄어들어 접은 자리가 어긋납니다.

나온 11장을 **순서대로 포개** 반으로 접고 가운데를 스테이플로 박습니다.
1장이 맨 바깥(표지), 11장이 한가운데(22·23쪽)입니다.

⚠️ **첫 부는 반드시 접어서 쪽 순서를 확인하세요.** 프린터마다 양면 넘김 방향이 달라,
설정이 어긋나면 짝수쪽이 뒤집혀 나옵니다. 1장을 접었을 때 **겉이 표지, 속이 2·43쪽**이면
맞습니다.

## 2-2. 표지를 색지에 따로 뽑을 때 (`--split`)

```
python generate_classics.py --split --pdf --booklet
```

표지 장을 **겉면만** 인쇄해 색지·두꺼운 종이에 쓰려는 방식입니다.

| 파일 | 인쇄 |
|---|---|
| `..._표지.pdf` | A4 가로 **1장 · 단면** — 색지에 (왼쪽 뒷표지 · 오른쪽 앞표지) |
| `..._본문_중철A4.pdf` | A4 **11장 · 양면** — 접어서 표지 안에 끼운다 |

**종이 12장**(지금보다 1장 늘어납니다).

⚠️ **왜 한 장이 느는가** — 중철에서 표지 장은 본디 네 면(겉 2 + 안 2)이고, 그 안쪽 두 면에
**차례 첫 쪽과 마지막 노트 쪽**이 실려 있습니다. 겉면만 인쇄하면 그 두 쪽이 갈 곳이 없어
본문이 그만큼 늘어납니다.

본문 44쪽은 쪽수가 그대로입니다 — **p1 이 앞표지 대신 속표지**, **p44 가 뒷표지 대신 줄노트**가
됩니다. 차례가 가리키는 쪽 번호(4·6·8…)도 하나도 안 바뀝니다.

⚠️ **색지를 쓰실 거면 연한 것**(크림·아이보리)으로 하세요. 앞표지는 흰 바탕에 교회 마크인데,
짙은 색지에서는 마크의 파랑·주황이 탁해집니다.

## 3. 글을 고칠 때

원고는 **`classics.json`** 한 파일입니다. `generate_classics.py` 는 건드리지 마세요.

```json
{ "no": 1, "day": 2, "date": "10/2(금)",
  "book": "루터 선집", "author": "마르틴 루터", "staff": "한충성 목사",
  "mark": "①", "title": "루터 선집 ①",
  "sub": "독일 크리스천 귀족에게 보내는 글",
  "excerpt": ["세례받은 사람은 …"],
  "scripture": "그러나 너희는 택하신 족속이요 …",
  "ref": "베드로전서 2:9" }
```

| 자리 | 무엇 | 화면 어디에 |
|---|---|---|
| `title` · `sub` · `author` | 제목·소제목·저자 | 고전 쪽 머리, 차례 |
| `excerpt` | 고전 발췌문 (문단 배열) | 고전 쪽 본문 |
| `scripture` · `ref` | 성경본문·출처 | 고전 쪽 아래 상자, 노트 쪽 머리 |
| `sub` 가 비면 | 차례에 「참된 목자 1」 꼴로 나온다 | — |

**편을 더하거나 빼면 쪽수가 달라집니다.** 중철은 4의 배수라야 해서, 모자란 만큼
빈 쪽이 자동으로 붙습니다(스무 편이면 딱 44쪽이라 빈 쪽이 없습니다).

## 4. ⚠️ 글을 고쳤으면 글씨 크기를 다시 재세요

```
python generate_classics.py --fit
```

들어가는 **가장 큰 글씨**를 찾아 알려 줍니다(한 단계에 3초쯤, 다 해서 1분 남짓).

```
   14.5pt  넘침 3쪽 [4, 22, 24]
   14.0pt  넘침 없음  ← 이 값을 쓰세요
```

나온 값을 `generate_classics.py` 의 **`FITTED_PT`** 에 적습니다.

⚠️ **어림으로 정하지 마세요.** 발췌문이 조금만 길어져도 어느 한 쪽이 넘치는데,
넘친 글자는 경고 없이 **잘려 나갑니다**. 지금 값(14.0pt)은 가장 긴 편(죄 죽이기 ① · 262자)이
정한 값입니다.

## 4-2. 줄 간격을 바꿀 때

```
python generate_classics.py --line 10 --lines        먼저 줄이 몇 개 잡히는지 본다
python generate_classics.py --line 10 --pdf --booklet  마음에 들면 그 값으로 뽑는다
```

**간격 하나만 고르면 나머지는 따라옵니다** — 한 줄에 쓰는 글자 수도, 말씀 칸 상한도
자동으로 다시 잡힙니다. 마음에 들면 `generate_classics.py` 의 **`LINE_MM`** 기본값을 고치세요
(이름에도 그 값이 들어가므로 결과물 이름이 함께 바뀝니다).

⚠️ **`--lines` 로 꼭 확인하세요.** 「단락 칸 최소」가 **6줄 아래로 내려가면 경고**가 뜹니다 —
말씀 칸이 쪽을 다 먹어 단락이 못 쓸 만큼 얕아졌다는 뜻입니다.

⚠️ 간격을 바꾸면 **`--fit` 도 다시** 돌리세요(왼쪽 고전 쪽은 안 바뀌지만, 습관으로 둡니다).

## 5. 서체

**Noto Serif KR**(본명조 계열) — 한국 출판물에서 널리 쓰는 명조입니다. SIL OFL 이라
상업적 사용도 재배포도 자유롭습니다.

저장소에는 넣지 않았습니다(두 벌 4.8MB). **처음 한 번 돌릴 때 자동으로 받아** `fonts/` 에
저장되고, 그 뒤로는 인터넷이 필요 없습니다.

⚠️ **서체를 바꾸면 `--fit` 을 반드시 다시 돌리세요.** 서체마다 글자 폭이 달라 같은 pt 라도
줄 수가 바뀝니다.

⚠️ 인쇄소가 서체를 문제 삼으면 `--no-bold` 로 **한 벌짜리 PDF** 를 낼 수 있습니다.
지금 서체는 굵기 두 벌 다 Type0(CID) 로 정상 임베딩되므로 쓸 일은 없습니다.
(전에 쓰던 빙그레체Ⅱ 는 이름 레코드가 비어 있어 크롬이 Type3 로 박았고,
그걸 경고로 잡는 인쇄소가 있습니다.)

## 7. 만든 것이 맞는지 확인하는 법

```
python generate_classics.py --fit        넘치는 쪽이 없는지
python generate_classics.py --lines      노트 쪽 줄이 몇 개씩 잡히는지
```

중철 순서는 **접어 보는 것이 가장 확실합니다**(2번 마지막 ⚠️).
PDF 안에서 확인하려면 1면이 `44 | 1`, 마지막 22면이 `22 | 23` 이면 맞습니다.
