# 기독교 고전과 함께하는 전교인 필사 — 만들기

A5 소책자 · 44쪽 · **A4 11장 중철**(포개 반 접고 가운데 스테이플).
펼치면 **왼쪽이 고전, 오른쪽이 필사·메모**.

## 1. 그냥 뽑기

```
cd booklet
python generate_classics.py --pdf --booklet
```

세 파일이 나옵니다.

| 파일 | 쓸 곳 |
|---|---|
| `기독교고전_전교인필사_A5.html` | 브라우저로 열어 모양 확인 |
| `기독교고전_전교인필사_A5.pdf` | **A5 44쪽 순서판** — 인쇄소에 넘기거나 화면으로 검토 |
| `기독교고전_전교인필사_A5_중철A4.pdf` | **A4 가로 22면** — 집·교회 프린터로 뽑아 접을 때 |

## 2. 집 프린터로 접어 만들기

`_중철A4.pdf` 를 **A4 가로 · 양면(짧은 쪽으로 넘김) · 실제 크기(100%)** 로 인쇄합니다.

⚠️ **「페이지에 맞춤」을 끄세요.** 켜면 살짝 줄어들어 접은 자리가 어긋납니다.

나온 11장을 **순서대로 포개** 반으로 접고 가운데를 스테이플로 박습니다.
1장이 맨 바깥(표지), 11장이 한가운데(22·23쪽)입니다.

⚠️ **첫 부는 반드시 접어서 쪽 순서를 확인하세요.** 프린터마다 양면 넘김 방향이 달라,
설정이 어긋나면 짝수쪽이 뒤집혀 나옵니다. 1장을 접었을 때 **겉이 표지, 속이 2·43쪽**이면
맞습니다.

## 3. 글을 고칠 때

원고는 **`classics.json`** 한 파일입니다. `generate_classics.py` 는 건드리지 마세요.

```json
{ "no": 1, "day": 2, "date": "10/2(금)",
  "book": "루터 선집", "author": "마르틴 루터", "staff": "한충성",
  "mark": "①", "title": "루터 선집 ①",
  "sub": "독일 크리스천 귀족에게 보내는 글",
  "excerpt": ["세례받은 사람은 …"],
  "scripture": "그러나 너희는 택하신 족속이요 …",
  "ref": "베드로전서 2:9" }
```

| 자리 | 무엇 | 화면 어디에 |
|---|---|---|
| `title` · `sub` · `author` | 제목·소제목·저자 | 고전 쪽 머리, 차례 |
| `excerpt` | 고전 발췌문 (문단 배열) | 고전 쪽 본문 |
| `scripture` · `ref` | 성경본문·출처 | 고전 쪽 아래 상자, 노트 쪽 머리 |
| `sub` 가 비면 | 차례에 `ref` 가 대신 나온다 | — |

**편을 더하거나 빼면 쪽수가 달라집니다.** 중철은 4의 배수라야 해서, 모자란 만큼
빈 쪽이 자동으로 붙습니다(스무 편이면 딱 44쪽이라 빈 쪽이 없습니다).

## 4. ⚠️ 글을 고쳤으면 글씨 크기를 다시 재세요

```
python generate_classics.py --fit
```

들어가는 **가장 큰 글씨**를 찾아 알려 줍니다(한 단계에 3초쯤, 다 해서 1분 남짓).

```
   14.5pt  넘침 3쪽 [4, 22, 24]
   14.0pt  넘침 없음  ← 이 값을 쓰세요
```

나온 값을 `generate_classics.py` 의 **`FITTED_PT`** 에 적습니다.

⚠️ **어림으로 정하지 마세요.** 발췌문이 조금만 길어져도 어느 한 쪽이 넘치는데,
넘친 글자는 경고 없이 **잘려 나갑니다**. 지금 값(14.0pt)은 가장 긴 편(죄 죽이기 ① · 262자)이
정한 값입니다.

## 5. 인쇄소가 「Type3 폰트」를 문제 삼으면

```
python generate_classics.py --no-bold --pdf --booklet
```

제목까지 본문 서체로 그려, PDF 안 서체가 **한 벌로 정리**됩니다.

왜 그런가 — 제목용 **빙그레체Ⅱ 파일에 이름 레코드가 비어 있어**, 크롬이 이것만 Type3 로
박습니다. 300dpi 로 뽑아 확인했을 때 **글자는 완벽하게 선명**했지만(벡터라 해상도 손실이
없습니다), 프리플라이트에서 Type3 를 경고로 잡는 인쇄소가 있습니다.

⚠️ **폰트 파일을 고쳐서 해결하려 하지 마세요** — 빙그레 서체는 라이선스가
**수정·재배포를 금지**합니다(상업적 사용은 무료).

## 7. 만든 것이 맞는지 확인하는 법

```
python generate_classics.py --fit        넘치는 쪽이 없는지
```

중철 순서는 **접어 보는 것이 가장 확실합니다**(2번 마지막 ⚠️).
PDF 안에서 확인하려면 1면이 `44 | 1`, 마지막 22면이 `22 | 23` 이면 맞습니다.
