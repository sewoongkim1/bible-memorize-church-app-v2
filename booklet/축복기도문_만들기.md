# 가정 축복 기도문 핸드북 만들기

A5 · 한 편 한 쪽 · 104편을 52편씩 두 권.

## 1. 그냥 뽑기

```
cd booklet
python generate_blessing.py 김세웅
```

`축복기도문_1권.html` · `축복기도문_2권.html` 이 나옵니다.
브라우저로 열어 **인쇄 → PDF로 저장**(용지 A5 · 여백 없음 · 배경 그래픽 켜기).

이름 자리를 그대로 두려면 이름을 빼고 `python generate_blessing.py` — 「홍길동」이 들어갑니다.

## 2. 몇 장만 보기

```
python generate_blessing.py 김세웅 --sample 3
```

`축복기도문_견본.html` — 앞에서 3편만, 표지·차례 없이. 손에 쥐어 볼 때 씁니다.

## 3. 줄 나누는 곳을 손으로 고치기

기도문을 어디서 줄바꿈할지 자동으로 정하지만, **마음에 안 들면 손으로 고칠 수 있습니다.**

### ① 지금 나뉜 대로 파일로 뽑는다

```
python generate_blessing.py --export
```

`줄나눔.txt` 가 생깁니다. 메모장으로 열면 이렇습니다.

```
=== 1 창조의 축복 (창세기 1:28-29)
하나님,
{이름}에게 복을 주시며
{이름}에게 말씀하여 주옵소서.
{이름}{이} 생육하고
...
```

### ② 고친다

- **여기 한 줄이 인쇄되는 한 줄**입니다. 나누려면 엔터, 붙이려면 한 줄로 합치세요.
- `{이름}` 은 인쇄할 때 성함으로 바뀝니다. **지우지 마세요.**
  `{이}` `{을}` `{은}` `{과}` `{으로}` 도 조사라 그대로 둡니다.
- `=== 3 이삭의 축복` 줄은 **건드리지 마세요**(어느 편인지 표시).
- 맺음말(예수님의 이름으로 축복하며 기도합니다. 아멘!)은 자동으로 붙으니 쓰지 않습니다.

### ③ 다시 뽑는다

```
python generate_blessing.py 김세웅
```

**줄나눔.txt 가 있으면 그 파일이 이깁니다.** 자동으로 나눈 것은 무시됩니다.

> 자동으로 돌리고 싶으면 `줄나눔.txt` 를 지우거나 이름을 바꿔 두세요.

### ④ 글자를 잘못 건드리면 알려 줍니다

돌릴 때마다 원문과 대조합니다.

```
!! 원문과 다른 편이 있습니다 — 글자가 지워졌거나 더해졌습니다:
   1번 창조의 축복
   그 편은 파일 내용 그대로 인쇄됩니다. 확인해 주세요.
```

⚠️ **막지는 않습니다** — 일부러 고치실 수도 있으니까요. 다만 조용히 지나가지는 않습니다.

## 4. ⚠️ 줄을 고친 뒤에는 넘치는 쪽을 다시 봐야 합니다

줄을 늘리면 그 쪽이 길어져 A5 한 쪽을 넘길 수 있습니다.
넘치는 쪽만 글씨를 한 단계 내리는 목록이 코드 안에 있습니다(`SMALL`).
그 목록은 **브라우저로 재서 얻은 것**이라, 줄나눔을 고치면 틀어집니다.

재는 법 — 만든 HTML 을 브라우저에서 열고 F12 콘솔에 붙여 넣으세요.

```js
var bad = [];
document.querySelectorAll(".page").forEach(function (p, i) {
  if (p.scrollHeight - p.clientHeight > 1) bad.push(i - 4);   // 편 번호(2권은 +52)
});
console.log("넘치는 편:", bad.join(", ") || "없음");
```

나온 번호를 `generate_blessing.py` 의 `SMALL` 에 `번호: 'p13'` 으로 더하면 됩니다
(13pt 로도 넘치면 `'p12'`).
